## 关键问题

1. BB 的「特质」与「出身」是两套东西：出身决定初始属性与成长上限（星级），特质是随机加减益。二者要分开建模。
2. RW 没有「角色等级」，只有 12 项技能等级 + 特质 + 心情。抄它就得放弃统一等级，改成"技能各自成长"。
3. 两游戏都不给玩家自由洗点（BB 无洗点，RW 靠训练/药物），这点要不要保留？

## 决策记录

| 决策 | 理由 |
|------|------|
| 加点模型抄 BB（每级 3 点 + 星级 roll） | 玩家每级要做 3 次取舍，决策密度高，且天然产生"这人该练什么"的判断 |
| 特质模型抄 RW（行为/心理维度 + 互斥组合） | RW 特质不止加减数值，还改行为（懒、暴躁、纵火），能驱动叙事 |
| 技能模型混合：BB 的 tier 解锁 + RW 的熟练度成长 | 纯 BB 只有 10 次点选机会，纯 RW 没有 build 感 |
