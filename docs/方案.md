# 宗门模拟器 · 山河图 —— 水墨风大地图方案

一个类似《觅长生》(修仙世界大地图) 与《战场兄弟》(程序化六边形战略地图) 的
游戏大地图 Demo。从**地图生成脚本**到**游戏贴图**再到 **WebGL 渲染**的完整实现。

直接双击 `index.html` 即可运行（零依赖、零构建，纯浏览器本地运行）；
或 `node server.js 8137` 后访问 <http://127.0.0.1:8137>。

---

## 1. 总体架构

```
index.html                 入口 + 水墨风 UI
js/
  noise.js                 可播种随机数 / Simplex 噪声 / fbm / 山脊噪声
  mapgen.js                世界生成器（纯数据，纯函数式管线）
  textures.js              程序化水墨贴图工厂（Canvas2D 笔触引擎）
  renderer.js              WebGL2 双通道渲染器（实例化六边形 + 水墨后处理）
  main.js                  相机 / 输入 / Canvas2D 标注层 / 小地图 / UI
server.js                  可选的本地静态服务器
assets/
  textures/paper.png       （可选）网络素材宣纸纹理，缺失时自动用程序化宣纸
```

数据流：

```
种子字符串
  → MapGen.generate()  →  World{ 7072 格六边形: 海拔/湿度/温度/群系/区域/聚落/道路/灵脉 }
  → InkTextures.build* →  atlas(墨色图集) + paper(宣纸) + noise(笔触噪声)
  → InkRenderer        →  Pass1: 7072 个六边形实例 → 离屏FBO
                          Pass2: 全屏水墨后处理 → 屏幕
  → main.js 标注层     →  Canvas2D 叠加: 道路/灵脉/聚落图标/区域名/图框/印章
```

## 2. 地图生成脚本（mapgen.js）

参考《战场兄弟》的分层程序化管线，全部可由种子复现：

| 步骤 | 方法 | 说明 |
|------|------|------|
| 1. 海拔场 | 域扭曲 Simplex fbm（5 倍频）+ 低频大洲遮罩 + 边缘衰减 | 造出主大陆、内海、群岛 |
| 2. 山脉 | 山脊噪声 `ridged = (1-\|n\|)²` 叠加 | 山脉呈线状走向而非圆斑 |
| 3. 水陆 | 海平面 0.40：深海 / 浅海 / 沙岸(带抖动海岸线) | |
| 4. 湿度 | fbm + 多源 BFS 距水加湿 | 近海湿润 → 森林，内陆干燥 → 沙漠 |
| 5. 温度 | 纬度 + 海拔递减 | 高山与南/北缘出雪峰 |
| 6. 群系平滑 | 六邻域多数投票 | 去除单格椒盐噪点，孤峰/孤沙回落 |
| 7. 碎岛清理 | 连通域 < 6 格沉海 | 海岸线干净 |
| 8. 区域 | 陆地 Voronoi (8~22 个种子) + 噪声扰动边界 | 按主导群系命名：苍莽林/黄沙漠/昆仑山脉… |
| 9. 水域命名 | 水体连通域 | 大水域 → 沧澜海，小水域 → 月牙湖 |
| 10. 聚落 | 泊松式最小间距散布 + 打分 | 宗门×5(喜靠山面水)、仙城×2、坊市×6、村落×10、秘境×4 |
| 11. 道路 | 六边形 A*（草地1 沙漠2.6 山地7 通行成本） | 每个聚落连最近的 1~2 个邻居，虚线墨路 |
| 12. 灵脉 | 自最高雪峰沿海拔梯度下山 | 朱砂点线，入海而止 |

命名系统：宗门（青云剑宗/太虚丹阁/百花谷…）、仙城、坊市、村落、区域、海域
全部由词库 + 种子随机拼装并去重，风格对齐《觅长生》。

## 3. 游戏贴图（textures.js）

水墨质感的三张程序化贴图（固定种子，每次生成一致）：

- **atlas 1024×512**：8 群系 × 4 变体，每格 128px。`列=群系、行=变体`。
- **paper 512×512**：宣纸底色 + 斑驳 + 纤维长丝 + 细点，`REPEAT` 平铺。
- **noise 256×256**：R=枯笔断裂噪声，G=细纤维，B=团渍。

笔触引擎（Canvas2D 模拟国画技法）：

| 技法 | 实现 |
|------|------|
| 枯笔飞白 | 主笔画多层低透明度叠加抖动 + 沿笔锋扫纸色细丝 |
| 晕染 | 大半径径向渐变水渍（透明→色→透明） |
| 皴法 | 山脊轮廓 + 自脊向左下的短披麻皴笔 |
| 椿点 | 树冠 = 5~8 个错落墨点簇 |
| 剪影山 | 线性渐变山体（峰浓谷淡）+ 积雪留白 |

> 网络素材：经检索采用 OpenGameArt CC0 无缝纸纹包
> <https://opengameart.org/content/paper-textures-seamless>（58MB，13 张 1500² CC0）。
> 若 `assets/textures/paper.png` 存在则自动替换程序化宣纸；缺失不影响运行。
> 水墨笔触风格参考 itch.io「ink」素材区与 Brusheezy 水墨笔刷，为实现层自绘。

## 4. WebGL 渲染（renderer.js，WebGL2）

**Pass 1 — 六边形实例化（1 次 drawArraysInstanced，7072 实例）**

- 每实例属性：格心(x,y)、图集索引(群系*4+变体)、海拔、随机哈希。
- 片元内解析六边形 SDF（`max(|x|, 0.5|x|+0.866|y|) - apothem`）裁形。
- RGB=水墨底色（采样图集），**A=群系 id/16**（供后处理做边缘检测）。
- 海面：按深度压暗 + 双层正弦波光（随时间流动）；陆地：海拔越高墨色越沉。

**Pass 2 — 全屏水墨后处理**

| 效果 | 方法 |
|------|------|
| 枯笔墨线 | 对群系 id 做 4 邻域边缘检测；**采样半径 = 0.85 世界像素 × 缩放**，线宽随缩放等比变化（远景自然变细变淡）；深海/浅海视为同类不画内线 |
| 墨线断续 | 线强 × 枯笔噪声阈值（smoothstep） |
| 海岸双线 | 线宽半径 + 3.4 倍远邻域两次水陆判别，海岸线更重 |
| 晕染外渗 | 颜色向对角方向做 4 tap 混合，**外渗半径同样等比** |
| 宣纸打底 | 世界坐标平铺宣纸纹理，正片叠底 48%（缩放时纸随图动，如一卷真正的画） |
| 纸纤维 | 细噪声微扰亮度 |
| 暗角 | 屏幕空间 vignette（镜头效果，不随地图缩放），图外露出纸底 |

**叠加层（Canvas2D，`<canvas id="overlay">`）**：虚线墨路（2.4 世界像素宽、间距 10/8）、
朱砂灵脉（3.0 世界像素、点距 4/12）、白描聚落图标（塔/城/坊/舍/菱晶，世界尺寸等比缩放，
仅设 0.55 倍下限防止缩到不可见）、区域名淡墨大字（按区域面积推导世界字号）、
双线图框（3.5/1.4 世界像素）、朱红「山河」印章。**所有标注均为世界坐标锚定，与地图等比缩放。**

## 5. 交互与 UI

- 拖拽/方向键平移，滚轮/双指捏合以光标为中心缩放，小地图点击跳转。
- 点击任意格 → 「山川志」面板：地界(区域)、地貌、海拔(丈)、润泽、去水、道路、聚落信息。
- 顶栏：干支纪年（由种子推导）、种子输入、山河重铸、另起一界、灵脉/注记开关。
- 左下：八群系图例；右下：小地图 + 视口框。
- URL 参数 `?seed=xxxx` 可复现同一世界。

## 6. 性能

- 全图仅 2 次 draw call（1 次实例化 + 1 次全屏三角形），7072 格 60fps 无压力。
- 世界生成 ~40ms、贴图生成 ~50ms，均在可交互时间内完成。

## 7. 运行与兼容

- 需要 WebGL2（2026 年所有主流浏览器均已支持）。
- `file://` 直开可用（贴图全程序化，无跨域问题）；HTTP 下自动增强网络纸纹。
- 不支持 WebGL2 时显示水墨风错误页「山河未成」。
