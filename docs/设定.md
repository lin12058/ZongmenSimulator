# 宗门模拟器 · 世界观设定

> 「诸仙万界」中的一个低维小世界——灵气刚刚苏醒，凡人尚不知头顶有仙人窥视。

---

## 〇、核心一页纸

- **你是谁**：诸仙万界的大修士，因天道约束无法真身降临此界。
- **你为什么在这里**：此方世界灵气复苏，天机已乱，你需要掌控这一界的天道。
- **你打算怎么做**：化身「系统」，借凡人之手开宗立派、纳徒炼法、扩张气运。
- **你的终极目标**：控制一方世界的**灵脉**，以灵脉定天道，以宗门镇气运。

> 一句话总结：**天道不容我身入，我便以「系统」为身，以「宗门」为手，控住这方世界的灵脉。**

---

## 一、人物设定：大修士／系统的化身

| 维度 | 设定 |
|------|------|
| 真身 | 诸仙万界某境的大修士，境界超脱本界上限 |
| 束缚 | 天道壁垒：真身踏界即遭反噬，只能将神识化作「系统」投影 |
| 化身形态 | 无固定形体，以「山河令」/「观天镜」/「气运盘」等器物为锚，向选中之人显化 |
| 行事风格 | 不争一时杀伐，重布局、重传承、重气运的绵长经营 |
| 对外身份 | 修士眼中只当作「上古传承」「天降机缘」；唯有宗门高层知悉幕后存在 |
| 初衷 | 灵气复苏若无人引导，此界将沦为万界的漏气之所、妖邪温床，故必须掌控 |

## 二、世界观

### 2.1 诸仙万界

- 诸界如星罗棋布，灵气有高下，仙道有兴衰。
- 大修士往来诸界需渡「天堑」，越高界限制越严，越低界反而束缚越多（规则稀薄、承载上限低）。

### 2.2 本界：灵气复苏

- 此界原本凡俗、仙道近乎断绝，如今灵脉自地底重新汇涌，万物得灵气灌洗。
- 复苏初期：生灵弱小、妖物初醒、旧的秩序瓦解，正是**抢占先机**的窗口期。
- 风险：若无人接手，灵气将搅乱天机，形成「乱界」，扰乱诸仙万界格局。

### 2.3 天道

- 天道即此界运行的根本规则：灵脉流向、气运聚散、劫数轮回均由其统摄。
- 天道未「认主」前，此界不稳；谁掌握灵脉中枢、镇得住气运，谁就能借力**执掌天道**。
- 化身「系统」正因天道规则制约，不能直接出手，只能间接经营。

## 三、核心设定：灵脉

灵脉是本作的气运与战力双核心，也是大修士化身的最终目标。

| 条目 | 说明 |
|------|------|
| 本质 | 天地灵气汇聚的脉络，犹地底江河 |
| 显化 | 地图上呈朱砂点线，从最高雪峰沿海拔梯度蜿蜒下山，入海而止 |
| 作用 | 汇聚灵气、孕养地脉、催生秘境/灵材/妖兽 |
| 权属 | 若宗门扎根其上、建立「灵枢」，便可抽取、引导、镇压灵脉 |
| 高地 | 占据灵脉的宗门气运与弟子修炼速度大幅提升 |

**决胜条件（暂定）**：累积够多灵脉节点、或控制某一「天脉中枢」者，可炼化本界天道。

---

## 四、化身系统：规则

「系统」是你在本界的唯一行事手段，法则如下：

1. **不可亲自动手**：伤害、灭杀、搬运物质一概不可，只能借宿体与宗门执行。
2. **借宿体显化**：选定「天命宗主」或多名「天命者」，赐予传承与任务。
3. **发布试炼**：通过任务、秘境、渡劫试炼引导宗门成长，换取气运反馈。
4. **时空无阻**：可观测全图、传讯全图，但天道遮蔽之下不能直接干预个体意志。
5. **气运即货币**：宗门气运是系统的「修为食粮」，也是兑换天机权柄的筹码。
6. **不能无中生有**：物资、功法、灵材需宗门自身经营，系统只给「门路」给「指引」。

> 系统 ≠ 金手指批发：你给的是方向和机缘，路要弟子自己走。

---

## 五、宗门

- **定位**：系统在凡间的「手臂」，承载传承、扩张领地、争夺灵脉的执行主体。
- **雏形**：可为无主之宗、可为落魄古宗、亦可从零建宗（对应开局选项）。
- **成长**：从「藏于深山」到「一宗压一域」，宗门品阶随气运/灵脉/弟子境界攀升。
- **领地**：宗门影响范围逐域扩展，与聚落、仙城、坊市联动，建立补给与情报网络。
- **传承**：功法、丹方、阵法、炼器术 —— 由系统授予种子，宗门自行繁衍推演。

## 六、目标拆解

| 阶段 | 目标 | 达成方式 |
|------|------|----------|
| 初期 | 扎根立足 | 建立宗门、收纳首批弟子、站稳一处灵脉细支 |
| 中期 | 逐鹿中原 | 扩展疆域、吞并/结盟周边势力、控制多处灵脉节点 |
| 后期 | 镇守中枢 | 逼近天脉中枢、整合界内气运 |
| 终局 | 炼化天道 | 掌控本界，收束灵气，确立此界秩序 |

## 七、与《山河图》机制的呼应

- **灵脉地图**：方案文档《山河图》中朱砂点线、沿海拔下行的灵脉，正是本设定的具象。
- **宗门选址**：泊松散布的宗门点位「喜靠山面水」，对应靠近灵脉高地的选址策略。
- **区域/聚落**：命名体系（宗门/仙城/坊市/村落/秘境）即是系统经营势力的棋盘。
- **进阶方向**：后续的势染色晕染、战雾探索、行军路径，皆服务于「掌控灵脉、镇服一方」的目标。
- **跨世界身份**：地图可视为大修士以「观天镜」俯瞰此界的实时视野。
