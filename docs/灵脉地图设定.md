# 《宗门模拟器》灵脉驱动地图生成设定

> 本文档定义「以灵脉为核心」的世界生成规则，替代旧版"先做山峰、后洒灵脉"的流程。
> 核心原则一句话：**先定灵脉，后造山河**——灵脉不是从地貌里找出来的，而是地貌要围绕它长出来。

---

## 一、总览：生成阶段（6 个步骤）

```
① 播种群落（大灵脉）      —— 决定全图骨架与群落个数，尽量稀疏
② 群落内布置次级灵脉      —— 每群落内按比例布 1大+中+小
③ 呼应五行（群落内）      —— 同一大灵脉内部按五行相生相克发育
④ 派生异灵根             —— 五行相生相克叠加，演化出异灵根
⑤ 地形抬升               —— 每个灵脉位点被抬成山 / 显化为水中的岛
⑥ 地貌表现（排列组合）    —— 属性在设定内随机组合成具体地貌（潭/瀑/熔岩…）
```

> **覆盖旧版错误**：五行影响**只在同一群落内部**发生，群落之间互不干涉。（旧版"跨群落相克压制"作废）

**纪律**：活泼的细节(海拔、湿度、植被)仍然用噪声生成，但**灵脉点位坐标与地形抬升必须确定性可复现**，与种子一一对应。

## 二、灵脉的三大级

| 等级 | 结构 | 五行显示 | 说明 |
|------|------|----------|------|
| **大灵脉** | 1 中心 + 6 个从属 = **七星（7格）** | 一种主灵根 | 世界的"气局中枢"，占位最稀 |
| **中灵脉** | 1 中心 + 6 个从属 = **七星（7格）** | 一种主灵根 | 大灵脉之间的次级节点 |
| **独立小灵脉** | **1 格单体** | 一种主灵根 | 灵气溢出的细枝末节 |

> **大/中灵脉用"一中心六从属"的七星结构，小灵脉是单点。**
> 每个"七星"视觉上合成一整块贴图（中心 + 六个方向延伸单元，像一朵花/星系），
> 而不是 7 个零散气泡。详见 §七 贴图约定。

## 三、群落结构与空间分布规则

### 3.0 群落定义

**一个群落 = 1 个大灵脉 + 若干次级灵脉**（同属一片地域、同一主灵根基调）。

每个群落内部灵脉的组成比例： **`大:[中]:[小] = 1 : [0~3] : [0~7]`**

- 大灵脉 0~1 个（有则必有，无则不成群落）；
- 中灵脉 0~3 个；
- 小灵脉 0~7 个。

> **向心聚敛**：灵脉数量**越靠近群落中央越密集**。中央是大灵脉，向外依次递减；次级灵脉（中/小）围绕中心呈"放射 + 从密到疏"排布。

### 3.1 最小间距（灵气"聚集"的代价）

灵气在汇聚点附近吸附，因此**群落与群落之间不能太近**，且**群落内部各灵脉之间**也需保持必要间距：

| 关系 | 最小中心距 |
|------|-----------|
| 大灵脉 ↔ 大灵脉（群落间） | ≥ `D_L_L`（远） |
| 大灵脉 ↔ 中灵脉（群内） | ≥ `D_L_M`（中） |
| 大灵脉 ↔ 小灵脉（群内） | ≥ `D_L_S`（中偏小） |
| 中灵脉 ↔ 中/小灵脉（群内） | ≥ `D_M`（小） |
| 小灵脉 ↔ 小灵脉（群内） | ≥ `D_small`（最小） |

> `D_L_L ≫ D_L_M > D_L_S > D_M > D_small`。群落内部允许相对密集，群落之间保持疏离。

### 3.2 播种顺序

1. **先播大灵脉**：用带最小间距的**泊松圆盘采样**铺全图，得到最稀疏的群落骨架（每点即一群落中心）。
2. **每群内部布次级**：以各大灵脉为中心，在"未被其他群落侵占"的范围内，按 `1:[0~3]:[0~7]` 比例与向心密度，布置中/小灵脉。
3. **密度向心**：半径内布置数量随离中心距离指数下降，中心最密、边缘渐疏。

### 3.3 群落边界（归属）

以**大灵脉中心**做 Voronoi，将全图地块划分给最近的群落。群落内所有地块共享该大灵脉的主灵根属性；中/小灵脉只在其局部范围产生灵气浓淡变化。

## 四、五行：灵根与相生相克（群落内）

### 4.1 五种基础灵根

| 灵根 | 五行 | 象征地貌/意象 |
|------|------|--------------|
| 金灵根 | 金 | 金属矿脉、石峰、剑意 |
| 木灵根 | 木 | 灵木、藤蔓、药田 |
| 水灵根 | 水 | 深潭、雾瘴、海眼 |
| 火灵根 | 火 | 熔岩、温泉、熔炉气 |
| 土灵根 | 土 | 厚山、矿藏、石脉 |

> **异灵根**（雷/风/冰/暗…）由五行组合或相生相克衍生（见 §4.3），不单独作为主灵根播种。

### 4.2 五行相生相克环（核心规则）

```
相生：木 → 火 → 土 → 金 → 水 → 木 （顺时针相生）
相克：金 → 木 → 土 → 水 → 火 → 金 （顺时针相克）
```

具体：`木生火、火生土、土生金、金生水、水生木`；`金克木、木克土、土克水、水克火、火克金`。

### 4.3 同群落内的相生相克作用（仅限内部）

> **关键约束：五行影响只在同一群落内部发生，群落之间互不干涉。**

- **主灵根自持**：大灵脉中心 = 群落的基调属性，保持本相。
- **相生发育**：靠近大灵脉的次级灵脉，趋向沿「相生环」向主灵根的方向生发。如同群落内水灵根旁生成木/金灵根。
- **相克制衡**：群落内部若出现相克属性，则被克一方（中/小灵脉）表现为**衰减、稀薄或异变**，不产生跨群落影响。
- 结果：每个群落内部是"主灵根 + 若干相生支脉 + 少量相克异变"的局部生态，群落之间互相独立。

### 4.4 异灵根派生

- 五行核心处：主灵根本色。
- 群落内部的相生叠加处：派生异灵根（如雷=火+金相冲、风=木+水相生、冰=水+金）。
- 相克被压制处：异变为"弱过渡属性"，仍属同一群落，不影响外部。

## 五、群落（对应"我的世界群系"）

### 5.1 群落 = 大灵脉域 + 主灵根

每个大灵脉域是一个**灵根群落**，具有：
- **一种主灵根**（域的基调）。
- 若干**副灵根**（域内灵气浓度较高的次位点，即中/小灵脉）。
- 专属的**植被/灵材/妖兽**风格（由属性演化确定）。

### 5.2 群落内部分布特征

- 主灵根锚定大灵脉中心。
- 中/小灵脉按"向心密度"围绕中心排布，越近越密。
- 相生支脉繁荣，相克支脉异变/稀薄。

## 六、地貌表现（属性 → 具体地貌的排列组合）

> 用户第 3 点：**不强制绑定单一形态**。同一灵根可以有多种地貌表现，组合符合设定即可。

一个灵根在地图上呈现的具体地貌，从以下**候选池**中依种子确定性地选取（可组合）：

| 灵根 | 候选地貌池（随机/组合取其一或叠加） |
|------|------------------------------------|
| **金灵根** | 白石岩峰 / 金属矿脉 / 剑意石林 / 铁锈山脊 / 金刚台地 |
| **木灵根** | 原始灵木林 / 藤蔓深谷 / 药田/灵植圃 / 千年树冠 / 青苔湿地 |
| **水灵根** | 深潭 / 瀑布 / 海眼(地涌泉) / 雾瘴湖泽 / 冰溪(与水相克分支) / 环山湖 |
| **火灵根** | 熔岩裂隙 / 活火山 / 地热温泉 / 焦土熔流 / 火晶洞窟 |
| **土灵根** | 厚土丘陵 / 矿藏山腹 / 石脉土台 / 黄土地 / 岩层断崖 |
| **异灵根** | 各相生相克派生：雷=雷击崖/紫电渊；风=风口峡谷/风蚀柱；冰=冰川/寒潭（水金相合）等 |

> **规则**：取貌完全由种子确定性生成，同一灵根在不同群落可见**不同具体地貌**，仅保证**意象不冲突、符合该灵根设定**。

## 七、贴图约定（七星合成大图）

"一个大灵脉 = 1 中心 + 6 从属"需要在视觉上**合成一整块贴图**。格位布局如下（俯视示意）：

```
        0←东北
  西北 ↗     ↘ 东
  西   ◄  中心  ► 东
  西南 ↙     ↖ 东南
        0←东南
```

- **中心格**：大灵脉的主体（核心灵气最浓）。
- **6 个从属格**：沿六边形 6 方向环绕（东、东南、西南、西、西北、东北），视觉上是中心向六个方向延伸的"气脉触手"，整体构成**一朵七星花/微型星系**。
- 渲染时六个从属与中心共用同一套样式主题，仅姿态各异（类似 MC 中一个多格合成体）。

> 中灵脉同构（1+6），只是规模/强度小于大灵脉；独立小灵脉只有中心 1 格。

## 八、地形保证（灵脉必定山/岛）

灵脉点位**先被确定**，然后地形向它**迁就**：

1. 对每个灵脉中心格，标记 `isVeinCenter = true`。
2. 对「陆上灵脉」：将中心及辐射范围内的海拔**抬升到高山档**（> 雪线或 ≥ 山态），保证"灵脉必定是山"。
3. 对落在「水中的灵脉」：在其周围**生成岛屿**（把一个低海拔水体格抬成高于海平面的岛），保证"水中的灵脉必定是岛"。
4. 其余非灵脉区域，海拔照旧用噪声场（低/海/平/谷）——**不强制有山**。

> 即：山不一定有灵脉，但**灵脉必是山**（或水中的岛）。

## 十一、聚落/宗门选址与灵脉的呼应

- 宗门选址评分加入**离灵脉中心距离**：太远无灵气，太近则已有专属从属。
- 聚落（仙城/坊市/村落）偏向落在灵脉域内灵气富集处。
- 秘境/灵材/妖兽在灵脉中心与从属格附近密集刷新。

## 九、灵气场（中心富、边缘贫，参考《无尽的拉格朗日》）

这是决定全图繁荣分布的**第一性规则**，先于所有群落与建筑：

1. **坐标原点觉醒**：世界以 `(0,0)` 为灵气中枢。
2. **直线距离衰减**：灵气浓度只由与原点的**欧几里得直线距离**决定（不是六边形网格距离）。
3. **半径封顶**：距离原点 **1000** 处灵气**衰减为 0**；世界以此为有灵气边界——半径 1000 以内为"灵界"，以外为凡俗无灵地带。
4. **单调递减**：距原点越近灵气越充足；密度曲线可配置（线性/缓急曲线），允许远处"灵气稀薄仍可聚落"、近处"灵气浓郁而繁华"。
5. **边界衰减（已实现）**：灵气强度**同一个场**再驱动两处衰减，各配一个系数（参考灵气强度曲线，`edgeKeep`）：
   - `EDGE_SEA_SP`（地形）—— 灵气强度低于该值起按曲线沉入海底，强度=0 处完全沉没；
     沉海放在**灵脉抬升之后**，故界外不会残留灵脉山，灵脉格覆写另加"仅陆地"守卫。
   - `EDGE_SETTLE_SP`（聚落）—— 灵气强度低于该值起聚落/秘境概率衰减，强度=0 处归零。
   ⇒ **边界外：全海洋、无聚落、无灵脉峰**；群落播种同受 `EDGE_SEA_SP` 约束（否则会留下水下空壳）。
   ⇒ `MapGen.spiritEdgeWorld()` 是边界世界半径的**唯一真源**，预览页/客户端的边界圈必须用它。

> 影响传导：灵气场决定群落密度与规模 → 群落决定灵脉质量与数量 → 灵脉决定建筑繁华度。**越靠内越强，越靠外越弱，1000 处归零。**

## 十、分层生成（先生态骨架，后功能建筑）

明确反对"生物群系 + 城市市场一次性整体生成"。改为**分层递进**，各层有依赖顺序：

```
① 灵气场铺底        —— 以原点为中心的灵气梯度面
② 群落生物群系播种  —— 在“灵界”内（半径≤1000）按灵气梯度播群落，越近越密
③ 群落内灵脉布局    —— 每群落按 1大+[0~3]中+[0~7]小 向心布置
④ 建筑/聚落选址    —— 依据灵脉位置与周边环境**逐处互相影响**而生成
⑤ 道路连接         —— 全部聚落定案后再连通枢纽
```

**第 4 层（建筑群生成）须满足的规则：**

| 影响因子 | 规则 |
|----------|------|
| 灵脉亲和 | 建筑类型靠近灵脉：修真城市/高阶坊市贴灵脉，世俗城镇靠边缘 |
| 资源吸引 | 灵材/矿脉/水眼附近 → 形成市场、交易集散 |
| 地形适配 | 平地水源 → 世俗城镇；险地 → 秘境或宗门 |
| 互斥间距 | 同类功能（城市/市场/聚落）间保持最小间距，避免紧挨成片 |
| 灵气梯度 | 随距原点变远逐级降繁华：中心大城 → 中环城镇 → 外缘村落 → 1000 外无灵凡俗 |

**第 5 层（道路）**：只在建筑与聚落全部落位后生成，连接各经济/修真枢纽。

## 十二、参数草案（全部可配置化，不进代码硬编码）

| 参数 | 草案值 | 说明 |
|------|--------|------|
| **群落半径** | **40 左右** | 单群落的半径规模 |
| 大灵脉最小中心距 `D_L_L` | 大数值 | 保证骨架稀疏 |
| 中灵脉最小中心距 `D_M_M` | 中数值 | 次级稀疏 |
| 独立小灵脉最小距 `D_small` | 小数值 | 仅"孤点"级隔离 |
| 七星半径 | 1 格（1+6） | 七格结构 |
| 灵脉域半径 | Voronoi 决定 | 看密度 |
| **灵气中枢原点** | `(0,0)` | 灵气最浓位置 |
| **灵气边界半径** | **1000** | 距原点 1000 处灵气=0 |
| **灵气衰减曲线** | 可配置（线性/缓/急） | 决定内外繁荣梯度 |
| **地形边界衰减** `EDGE_SEA_SP` | 0.30 | 灵气强度低于此值起沉海（界外全海洋）；0=硬边界 |
| **聚落边界衰减** `EDGE_SETTLE_SP` | 0.35 | 灵气强度低于此值起聚落概率衰减（界外无聚落）；0=硬边界 |
| 群落密度-灵气耦合指数 | 可配置 | 越靠内群落越密 |
| 建筑互斥最小间距 | 按功能分类配置 | 城市/市场/聚落各自间距 |
| 建筑-灵脉亲和权重 | 按建筑类型配置 | 修真城/坊市/世俗城分层贴靠 |
