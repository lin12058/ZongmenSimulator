# 修仙版 X4 经济：结构映射与最小闭环

设计时间：2026-11-19　｜　对象：把《X4：基石》的经济结构迁移到修仙题材

一句话结论：**不要换皮，要换"经济主体"。X4 的舰船是修士，船厂是宗门，战争是渡劫与宗门战。把"人"当成可培养、可装备、可损耗的舰船，这套经济才成立；只把"能量电池"改成"灵石"、"飞船"改成"飞剑"，玩家一眼就能看出是科幻换皮。**

如果只记三件事：

1. **修士 = 舰船**：宗门花资源培养弟子，弟子出去打仗/渡劫，死了再培养。
2. **渡劫 = 战争**：每一次突破都是一次大额消耗，失败则身死道消，资源归零。
3. **灵石 = 货币 + 燃料**：它既是钱，也是驱动阵法和丹火的能源。花掉它就不能存，存着就不能花。

---

## 一、先判断：哪些能换，哪些不能

| X4 的机制     | 修仙能直接换吗  | 原因                        |
| ---------- | -------- | ------------------------- |
| 货物全真、货币半假  | 能，而且更合适  | 宗门有海量灵石，但灵材/灵脉是有限的；稀缺性在货上 |
| 商品链与配方     | 能        | 炼丹、炼器、画符天然就是配方            |
| 库存定价与坊市    | 能        | 坊市、拍卖会、黑市都是现成的交易场         |
| 物流与仓储      | 能，但要换载体  | 储物袋、飞舟、商队、传送阵             |
| 第一人称飞行     | 不能       | 修仙不是飞行模拟，玩家要的是"人"和"境界"    |
| 舰船作为消耗品    | 不能直接换    | 舰船没名字，修士有名字；玩家会心疼         |
| 星区与跳跃门     | 不能直接换    | 修仙地理是山脉、洞天、灵脉、传送阵         |
| Xenon 机械军团 | 能换，但要换逻辑 | 魔道/妖族也要吃灵脉，不能凭空刷          |

**换皮陷阱**：灵石当电池、飞船当飞剑、宗门当空间站。这样换完，游戏还是"采矿—造厂—造船—打仗"，只是模型换成了古风。玩家玩两小时就会发现：这不就是太空游戏吗？

**正确的换法**：保留 X4 的"经济结构"（货物、产能、物流、需求、信息），换掉"经济主体"（谁在生产、谁在消耗、为什么消耗）。修仙题材恰好提供了一个比太空更自然的消耗理由：**修炼本身就是要烧资源的**。

## 二、核心映射：修士就是舰船

### 2.1 两条主循环长得一模一样

X4：

```
矿石 → 精炼金属 → 船体/引擎/武器 → 舰船 → 战争被击毁 → 船厂再下单
```

修仙：

```
灵矿 → 灵材 → 丹药/法器/符箓 → 修士 → 渡劫/宗门战身死 → 宗门再收徒
```

区别只在"舰船"换成了"人"。而"人"比"舰船"多三样东西：**资质、境界、道心**。这三样分别落在船体、功法和船员三个位置：

| X4 舰船 | 修仙修士    | 作用          |
| ----- | ------- | ----------- |
| 船体    | 肉身/灵根   | 决定基础强度和成长上限 |
| 引擎    | 功法/身法   | 决定移动、逃跑、追击  |
| 武器    | 法术/飞剑   | 决定输出        |
| 护盾    | 护体灵光/护甲 | 决定生存        |
| 船员    | 道心/神识   | 决定抗性、控制、情报  |
| 造船厂   | 传道堂/丹房  | 把资源变成修士     |
| 蓝图    | 功法/丹方   | 决定能造什么、造多好  |
| 船坞队列  | 收徒/培养队列 | 决定产出节奏      |
| 舰船被击毁 | 身死道消    | 资源永久消失      |
| 逃生舱   | 元婴出窍/夺舍 | 一次昂贵的"再来一次" |

### 2.2 必须做"两层人"：外门与内门

X4 的经济建立在"舰船可以随便死"上。修仙游戏不能这样：玩家会给每个弟子起名字，死了会心疼，死了就不想玩了。

解法是**把"人"分成两层**：

| 层级    | 作用          | 经济角色       | 死亡处理          |
| ----- | ----------- | ---------- | ------------- |
| 外门弟子  | 采矿、种田、跑商、守山 | 可消耗的"舰船"   | 批量补充，只报数字     |
| 内门弟子  | 带队、探索、战斗    | 有名字的"旗舰"   | 重伤/道伤/跌境，不轻易死 |
| 真传/长老 | 镇派、决策、传承    | 不可替代的"主力舰" | 死亡是剧情事件       |

**经济跑在外门弟子身上，故事跑在内门弟子身上。** 这样既保留了 X4 的"损耗—补充"循环，又不会让玩家因为死了个工具人而读档。

### 2.3 修士的"装备"就是舰船的"配装"

一个筑基弟子出门，身上要带：

- 本命法器（输出）
- 护身法衣（防御）
- 丹药（补给/突破）
- 符箓（一次性爆发）
- 阵盘（撤退/封锁）

这和 X4 给船装武器、护盾、引擎、无人机、导弹是一回事。**区别在于：修士的装备会随着境界提升而换代，旧装备可以下放给外门弟子。** 这形成了一条"装备梯田"：真传用新的，内门用旧的，外门用淘汰的。比 X4 的"船一炸全没"更有经营感。

## 三、三个 sink：渡劫、宗门战、妖兽潮

X4 只有一个大 sink：战争。修仙可以做得更好，因为它有**三种不同节奏的消耗**。

| sink   | 触发         | 消耗什么                    | 节奏        | 玩家的选择                |
| ------ | ---------- | ----------------------- | --------- | -------------------- |
| 渡劫     | 弟子修为到瓶颈    | 渡劫丹、护身符、本命法宝（失败则毁）、大量灵石 | 可预测，按月/按年 | 推迟（寿元/心魔风险）或硬闯（失败身死） |
| 宗门战    | 灵脉/洞府/功法争夺 | 弟子、法器、符箓、丹药             | 不可预测，按事件  | 站队、中立、发战争财           |
| 妖兽潮/魔潮 | 定期或灵脉异动    | 防御工事、守山弟子、阵盘            | 周期性，按季节   | 加固、迁移、主动清剿           |

### 3.1 渡劫：把"造船"变成"考试"

X4 的船厂是"下单—等待—交付"。修仙的传道堂是"收徒—培养—渡劫"。

一个弟子从练气到筑基，需要：

- 足够的灵气（洞府/灵脉）
- 足够的丹药（筑基丹）
- 足够的实战（心性）
- 一次渡劫（成功率判定）

**渡劫就是交船仪式。** 成功了，宗门多一个筑基战力；失败了，弟子身死，丹药和法宝全毁，宗门要重新培养。这个设计比 X4 的"船被炸了"更有戏剧性，因为玩家认识这个弟子。

为了让"渡劫"不变成纯随机，建议做成**可干预的成功率**：

- 渡劫丹品质 +20%
- 护身符 +15%
- 本命法宝 +10%
- 阵盘/洞府灵脉 +10%
- 道心/心境 +5%
- 魔道捷径 +30%，但留下道伤/心魔

玩家可以选择"稳"（多花资源）或"赌"（少花资源）。这就是 X4 的"给船装好装备再上战场"的变体。

**渡劫不是私事。** 雷劫会暴露位置，引来妖兽、仇家、其他宗门。玩家可以选择：

- 在宗门大阵内渡劫：安全，但消耗大量灵石/阵盘
- 在荒野渡劫：便宜，但可能被劫修/妖兽打断
- 在魔渊渡劫：成功率高，但可能入魔

这让"渡劫"同时是经济事件、战斗事件和外交事件，而不是一个进度条。

### 3.2 宗门战：把"国家战争"变成"门派斗法"

X4 的阵营战争是背景模拟，玩家可以参与也可以发战争财。修仙的宗门战可以更具体——**目标是"夺"，不是"灭"**。灭门会引来正道联盟围剿、天谴，或者让魔道趁虚而入。所以战争的目标通常是：

- 夺灵脉：把对方的灵脉节点抢过来，逼对方迁宗
- 夺功法：抢传承玉简/丹方，而不是杀光弟子
- 夺弟子：逼天才弟子改投门墙
- 夺香火：控制凡人村落，断对方的灵石/物资来源

宗门战消耗的是**弟子和法器**，摧毁的是**洞府和灵田**。这刚好对应 X4 的"舰船战损 + 空间站被毁"。这让宗门战变成"有限战争"，而不是"一键灭国"。玩家可以选择"打服"而不是"打死"，也可以选择"发战争财"——卖丹药/法器给两边。

### 3.3 妖兽潮：把"Xenon"变成"天灾"

X4 的 Xenon 是永久威胁，也在同一套经济里。修仙的妖兽潮可以做成：

- 灵脉异动 → 妖兽暴动 → 冲击山门
- 魔渊封印松动 → 魔气外泄 → 魔物入侵
- 古修遗府开启 → 妖兽/傀儡守护 → 探索风险

**关键：妖兽也要吃灵脉。** 它们不是凭空刷的，而是被灵脉吸引来的。玩家可以：

- 加固山门（消耗灵材/阵盘）
- 迁移洞府（放弃灵脉，损失产能）
- 主动清剿（消耗弟子/法器，获得妖兽材料）

这比 X4 的"Xenon 无限刷"更有因果感。

## 四、商品链：四层商品，三角收口

### 4.1 层级

| 层级     | 商品              | 作用          |
| ------ | --------------- | ----------- |
| T0 原料  | 灵矿、灵草、妖兽材料      | 采矿/种植/狩猎获得  |
| T0 能源  | 地火/下品灵石（灵脉决定产出） | 驱动丹房/器堂/阵法  |
| T1 中间品 | 灵材、丹液、兽魂        | 三条并行的加工线    |
| T2 成品  | 丹药、法器、符箓        | 两两组合，服务修士   |
| T3 终产品 | 本命法宝、渡劫套装       | 渡劫/宗门战的最终消耗 |
| T4 组织  | 修士、洞府、宗门大阵、飞舟   | 最终被消耗或建造    |

### 4.2 配方：三个中间品，两两组合

```
灵材 + 丹液 → 丹药
灵材 + 兽魂 → 法器
丹液 + 兽魂 → 符箓

法器 + 兽魂 → 本命法宝
丹药 + 符箓 → 渡劫套装
```

| 产品   | 配方        | 用途           |
| ---- | --------- | ------------ |
| 灵材   | 灵矿 + 地火   | 法器/丹药的基础     |
| 丹液   | 灵草 + 地火   | 丹药/符箓的基础     |
| 兽魂   | 妖兽材料 + 地火 | 法器/符箓的基础     |
| 丹药   | 灵材 + 丹液   | 修炼/疗伤/突破     |
| 法器   | 灵材 + 兽魂   | 战斗/护身        |
| 符箓   | 丹液 + 兽魂   | 一次性爆发/防御     |
| 本命法宝 | 法器 + 兽魂   | 弟子渡劫/战斗的核心装备 |
| 渡劫套装 | 丹药 + 符箓   | 渡劫专用，失败即毁    |

> 为简化，表中只列主料。实际每一步加工都要额外消耗**地火**或**下品灵石**（相当于 X4 的能量电池）。地火是固定能源，建在火山/地脉旁才便宜；下品灵石是可携带能源，可以随商队走，但更贵。这个差别会直接影响"丹房建在哪"。

**为什么是三角，不是树？**

- 三条中间线（灵材/丹液/兽魂）任意两条都能组合，任何一条短缺都会影响两个成品。
- 深度只有四层，玩家不用背六层中间品。
- 三个中间品对应三种采集方式（矿/草/兽），让地图上的三种资源点都有意义。

### 4.3 用"道统"做阵营专属链

X4 的 Terran/Teladi 专属链，在修仙里可以换成"道统"：

| 道统 | 专精 | 独占资源    | 专属产品      | 贸易边界            |
| -- | -- | ------- | --------- | --------------- |
| 剑修 | 攻伐 | 剑石/剑脉   | 飞剑、剑丸     | 不用丹药做主材，但需要丹药辅助 |
| 丹修 | 炼丹 | 灵草/药园   | 高阶丹药      | 丹药自给，但法器靠买      |
| 器修 | 炼器 | 灵矿/地火   | 法器、阵盘     | 法器自给，但丹药靠买      |
| 阵修 | 阵法 | 阵基/灵脉   | 护山大阵、传送阵  | 阵法自给，但战力靠弟子     |
| 体修 | 肉身 | 妖兽材料/猎场 | 淬体秘药、肉身法宝 | 近战强，但远程/阵法弱     |
| 魔修 | 捷径 | 魔气/血魂   | 魔功、魔器     | 进度快，但被正道排斥      |

**贸易边界的作用**：剑修宗门不能拿丹修的"金丹"去炼飞剑，但可以拿飞剑去换丹药。每个道统都有"我不产出、但我需要"的东西，于是坊市和商队才有存在意义。

小体量游戏建议只做 **3 个道统**（比如剑修/丹修/器修），否则玩家会被六套配方劝退。

## 五、价格：坊市库存定价

### 5.1 三价与库存插值

和 X4 一样，每种商品有最低价、平均价、最高价。坊市的成交价按库存比例在区间内浮动：

- 库存少 → 价格靠近最高价（稀缺）
- 库存多 → 价格靠近最低价（滞销）

示例（单位：下品灵石，仅示意比例，不是平衡数值）：

| 商品   |  最低 |  平均 |  最高 |
| ---- | --: | --: | --: |
| 灵矿   |   2 |   3 |   4 |
| 灵草   |   3 |   5 |   7 |
| 妖兽材料 |   5 |   8 |  12 |
| 灵材   |  12 |  18 |  25 |
| 丹液   |  10 |  15 |  22 |
| 兽魂   |  18 |  28 |  40 |
| 丹药   |  40 |  60 |  85 |
| 法器   |  55 |  80 | 110 |
| 符箓   |  35 |  50 |  70 |
| 本命法宝 | 150 | 220 | 300 |
| 渡劫套装 | 200 | 300 | 420 |

**看比例，不看绝对值**：从灵矿到渡劫套装，价值放大约 100 倍。这个倍率决定了"种田—加工—渡劫"的经济阶梯有多长。倍率太低，玩家没有升级动力；倍率太高，中间品会被跳过。绝对值可以整体放大 10 倍（比如渡劫套装 3000 下品 = 30 中品），只要保持阶梯比例即可。

### 5.2 灵石的双重角色

这是修仙版最值得做的经济设计：**灵石既是货币，也是燃料。**

- 下品灵石：驱动丹火、阵法、传送阵，是消耗品
- 中品灵石：大宗交易/宗门储备，是货币
- 上品灵石：战略资源，用于高阶阵法/渡劫

**兑换关系**：100 下品 = 1 中品，100 中品 = 1 上品；反向兑换有损耗（比如 1 中品只能换 90 下品）。这就形成了"能源→货币"的漏斗：你越生产，越需要下品灵石；你想存钱，就得换成中品/上品，但会损失流动性。

**好处**：

- 玩家不能无脑囤钱，因为生产要烧灵石。
- 宗门战争打的是灵石储备，不是数字。
- 灵石矿/灵脉成为战略目标，而不是普通资源点。

**风险**：

- 如果灵石产出太快，会通货膨胀；太慢，会卡死生产。
- 建议：灵脉产出有上限，且会缓慢衰减/再生，形成"灵脉周期"。

### 5.3 信息是资源

| X4    | 修仙版       | 作用          |
| ----- | --------- | ----------- |
| 卫星    | 探子/眼线     | 盯住坊市价格/宗门动向 |
| 贸易订阅  | 商会通票/情报贩子 | 长期看到远方价格    |
| 舰船扫描  | 神识        | 高修为者扫描一片区域  |
| 星区可见度 | 阵法遮蔽      | 宗门大阵可以屏蔽神识  |

**神识的设计要点**：它不能免费全图。修为越高，范围越大；但使用神识会被同阶/更高阶发现，暴露自己的位置。这就把"信息"变成了有风险的资源，而不是开图工具。

### 5.4 交易场

- **坊市**：日常买卖，价格随库存浮动
- **拍卖会**：稀有功法/法宝/丹药，价高者得
- **黑市**：魔道物品/违禁丹药，价格高但会被正道查抄
- **宗门内部**：贡献点/月例，不走灵石，走"内部结算"

内部结算是大宗门锁死资源的方式：弟子用贡献点换丹药，宗门不对外卖。玩家后期也会这么做——把关键物资锁在宗门内部，只把低端产品卖到坊市。

## 六、生产：宗门是一台有人的机器

### 6.1 宗门由什么组成

| 建筑/模块   | 作用        | 是否必需      |
| ------- | --------- | --------- |
| 灵田/药园   | 产灵草/灵米    | 必需（食物/丹药） |
| 丹房      | 炼丹        | 必需（丹药线）   |
| 器堂      | 炼器        | 必需（法器线）   |
| 阵堂      | 画符/布阵     | 可选（符箓/防御） |
| 传道堂     | 收徒/传授功法   | 必需（修士线）   |
| 膳堂      | 加工灵米/辟谷丹  | 必需（人口）    |
| 库房      | 存灵材/丹药/灵石 | 必需        |
| 山门/护山大阵 | 防御        | 必需（妖兽潮）   |
| 聚灵阵/灵脉  | 提供灵气      | 必需（产能）    |
| 洞府      | 宗主/长老修炼   | 可选（高阶战力）  |

> 灵米/辟谷丹属于"人口维持"的二级循环，不计入后面的 12 种主链商品。它们的作用相当于 X4 的食物和医疗：不参与造船链，但断了弟子就跑。

### 6.2 弟子：食物换产能

- 外门弟子负责采矿、种田、跑商、守山
- 弟子要吃灵米/辟谷丹，消耗灵气
- 断粮 → 弟子流失/哗变 → 产能下降
- 灵脉浓度越高、膳堂越好，弟子增长越快
- 长老/管事可以提升效率，但高阶修士不愿做杂务

这和 X4 的"劳动力吃食物+医疗换增产"是同一个结构。区别是：**修仙版的"劳动力"有修为，可以升级成战力，也可以叛逃/入魔。** 这让"人"既是生产要素，又是风险源。

### 6.3 灵脉：把地点写进配方

X4 的阳光强度决定能量电池产出。修仙版的灵脉浓度决定：

- 弟子修炼速度
- 丹房/器堂的产能
- 阵法的强度
- 灵石矿的再生速度

| 地点   | 灵脉浓度 | 特点             |
| ---- | ---- | -------------- |
| 洞天福地 | 极高   | 修炼快，但被所有宗门盯着   |
| 灵脉节点 | 高    | 适合建宗，争夺激烈      |
| 普通山地 | 中    | 安全，但上限低        |
| 绝灵之地 | 极低   | 无法修炼，但可能藏有古修遗府 |
| 魔渊   | 负    | 魔气浓郁，魔修圣地，正道禁区 |

**地点不是背景板，是生产函数。** 玩家选山门，本质上是在选"产能—安全—争夺"的三元权衡。

### 6.4 库房与月例：隐形门槛

宗门库房和 X4 的站点账户一样：

- 库房没灵石 → 不能买灵材、不能发月例
- 月例停发 → 弟子流失、长老不满
- 丹房停工 → 弟子突破失败 → 战力下降

新宗门"建好了却运转不起来"，最常见的原因不是建筑不够，是**没有流动资金**。这让"开宗"除了建设成本，还有一笔运营资金门槛。

### 6.5 管事与神识：两种半径

| 角色    | 决定什么    | 升级方式     |
| ----- | ------- | -------- |
| 管事/掌柜 | 商队/采购半径 | 管理经验、商学院 |
| 长老    | 分舵/战区半径 | 修为、威望    |
| 宗主    | 宗门总范围   | 境界、声望    |
| 神识    | 情报半径    | 修为、功法、阵法 |

X4 用"管理员星级"决定物流半径，修仙版可以用"管事能力 + 长老修为"双重决定。这样玩家既要培养战力，也要培养管理人才，形成"人才配置"的 puzzle。

## 七、玩家路径：从散修到宗主

| 路径   | 启动成本 | 利润来源      | 风险       | 上限      |
| ---- | ---- | --------- | -------- | ------- |
| 散修   | 极低   | 采药/猎妖/接任务 | 妖兽、劫修、寿元 | 低，个人战力  |
| 坊市商人 | 低    | 地区价差/信息差  | 劫商、黑市查抄  | 中，商队网络  |
| 炼丹师  | 中    | 加工增值      | 炸炉、丹方泄露  | 中高，丹药垄断 |
| 炼器师  | 中    | 装备增值      | 材料浪费、器劫  | 中高，法器垄断 |
| 宗主   | 高    | 全产业链/宗门战争 | 灭宗、弟子叛逃  | 最高，洞天霸主 |

### 7.1 镜头问题：玩家是一个人，还是一个宗门？

这是修仙版最大的设计难点。X4 的玩家是一个"可以在任何船上附身"的意识；修仙的玩家通常是一个有身体的人。

| 方案    | 做法               | 优点            | 缺点               | 适合    |
| ----- | ---------------- | ------------- | ---------------- | ----- |
| 宗主视角  | 玩家是宗主，管理长老/弟子/分舵 | 最接近 X4，能做宏观经济 | 个人代入弱，像经营游戏      | 管理型   |
| 散修视角  | 玩家是一个人，带几个随从/商队  | 代入强，符合修仙叙事    | 经济规模小，做不出 X4 的深度 | RPG 型 |
| 分身/神识 | 玩家可以用分身/神识附体弟子   | 兼顾宏观与微观       | 需要叙事解释，容易失控      | 混合型   |

**建议**：如果目标是"X4 式经济"，选宗主视角 + 分身附体。平时在宗门大殿看账、派商队、调长老；遇到关键战斗/探索，用"分身/神识"附体一个弟子下场。这样既保留了 X4 的"宏观经营 + 微观介入"，又符合修仙的"本人不在场"的逻辑。

### 7.2 自动化阶梯

1. **自己跑**：散修阶段，自己采药、自己卖、自己打。
2. **管事代管**：建坊市店铺/仓库，雇管事，设定收购/出售价。
3. **商队/分舵**：管事带商队，长老带分舵，形成网络。
4. **傀儡/阵法**：用傀儡运输、传送阵调货，减少人力。

每一层的瓶颈不同：先是本金，再是管事，再是灵脉/阵法，最后是人才。

## 八、设计意图与风险

### 8.1 为什么修仙适合这套经济

1. **修炼本身就是资源转化**：灵气→修为→战力，天然有"投入—产出"。
2. **渡劫是天然的 sink**：每次突破都要烧大量资源，失败还会归零。
3. **宗门是天然的组织单位**：有层级、有分工、有领地、有战争。
4. **灵脉是天然的地理**：浓度差异直接决定产能，地图有意义。
5. **道统是天然的阵营**：不同修炼路线需要不同资源，形成贸易边界。
6. **境界是天然的科技树**：练气/筑基/金丹/元婴，比"科技等级"更有叙事感。

### 8.2 五个风险

| 风险           | 表现                 | 解法                               |
| ------------ | ------------------ | -------------------------------- |
| 换皮感          | 玩家觉得是"太空游戏换古风"     | 让修仙特有的选择（道统/渡劫/心魔）影响经济，而不只是换名字   |
| 数值膨胀         | 元婴修士一个人顶一个宗门，经济崩坏  | 高阶修士数量稀少、维护成本极高；用"境界压制"而不是"数值碾压" |
| 个人英雄 vs 系统管理 | 玩家想修仙，游戏逼他管账       | 双镜头：宗主管宏观，分身下副本；让管理有"收益感"        |
| 死亡惩罚         | 玩家读档，经济循环失效        | 外门可消耗，内门重伤/跌境，真传死亡是剧情            |
| 玩家预期         | 修仙玩家要爽文节奏，X4 玩家要慢热 | 前期给个人成长爽点，中期给宗门经营，后期给渡劫/飞升       |

### 8.3 一个必须做的取舍

**不要做"银河规模的修仙"。** X4 有几十个星区、上百个空间站，是因为它有十年积累和成熟引擎。小团队做修仙版，建议：

- 一张地图：一个洞天/山脉，3–5 个宗门
- 12 种商品：3 原料 + 1 能源 + 3 中间品 + 3 成品 + 2 终产品
- 3 个道统：剑修/丹修/器修（或剑/丹/阵）
- 2 个主 sink（渡劫 + 宗门战）+ 1 个周期事件（妖兽潮）
- 1 个核心循环：采灵→炼丹/炼器→培养弟子→渡劫/守山→再采灵

## 九、修仙版最小闭环（12 种商品）

### 9.1 商品表

| 层级  | 商品      | 输入        | 去向          |
| --- | ------- | --------- | ----------- |
| 原料  | 灵矿      | —         | 灵材          |
| 原料  | 灵草      | —         | 丹液          |
| 原料  | 妖兽材料    | —         | 兽魂          |
| 能源  | 地火/下品灵石 | —         | 所有加工        |
| 中间品 | 灵材      | 灵矿 + 地火   | 丹药、法器       |
| 中间品 | 丹液      | 灵草 + 地火   | 丹药、符箓       |
| 中间品 | 兽魂      | 妖兽材料 + 地火 | 法器、符箓       |
| 成品  | 丹药      | 灵材 + 丹液   | 修炼、疗伤、渡劫、月例 |
| 成品  | 法器      | 灵材 + 兽魂   | 战斗、护身、本命法宝  |
| 成品  | 符箓      | 丹液 + 兽魂   | 一次性爆发、渡劫    |
| 终产品 | 本命法宝    | 法器 + 兽魂   | 弟子核心装备      |
| 终产品 | 渡劫套装    | 丹药 + 符箓   | 渡劫专用，失败即毁   |

### 9.2 四个消耗口

1. **渡劫消耗**：每个弟子突破时消耗一套渡劫套装 + 本命法宝（失败则毁）+ 大量灵石。失败则弟子身死或道伤。
2. **宗门战消耗**：弟子战死、法器损毁、洞府被破、灵田被烧。
3. **妖兽潮消耗**：守山弟子、阵盘、防御工事被消耗；打赢了能收妖兽材料，打输了丢灵脉。
4. **日常维持**：弟子月例（丹药/灵米）、灵田维护、阵法灵石、灵脉衰减。

### 9.3 反雪球机制

X4 最大的问题是"没有维护费，雪球不可逆"。修仙版必须加：

- **弟子月例**：每个弟子每月吃丹药/灵米，不付就流失。
- **灵田维护**：灵田要灵气/灵石，不维护就减产。
- **灵脉衰减**：宗门规模越大，灵脉消耗越快；需要不断开新灵脉/布聚灵阵。
- **心魔/道伤**：弟子突破失败会留下道伤，持续消耗丹药；不治会跌境/入魔。

这四条让"扩张"自带成本，不会变成无限矿船。


### 9.4 验收标准

1. 玩家能在 30 分钟内跑通"采灵矿 → 炼灵材 → 炼丹药 → 弟子服丹 → 渡劫"一圈。
2. 停掉任意一种原料，成品产线在 10 分钟内可见地停摆。
3. 没有宗门战时，丹药/法器库存堆满、价格下跌、丹房减产；宗门战/妖兽潮时，价格回升、丹房加班。
4. 玩家能在一个面板上看到"我每小时赚多少灵石、瓶颈在哪、哪个弟子要渡劫"。
5. 玩家不建灵田/膳堂，弟子增长慢、产能低；建了，就要持续投入灵草/灵石。

## 十、与"洞穴探索"的接口

如果这个修仙版要长在现有的洞穴项目上，映射关系非常顺：

| 现有洞穴元素 | 修仙版 | 说明 |
|---|---|---|
| 洞穴 | 洞府/灵脉 | 洞穴就是宗门的根基 |
| 深度 | 灵气浓度/危险度 | 越深灵气越浓，妖兽越强 |
| 矿车/升降机 | 灵材运输 | 玩家能站在旁边看货在流 |
| 怪物 | 妖兽/魔物 | 妖兽潮的来源 |
| 深渊 | 魔渊/封印 | 魔气外泄，魔修/魔物入侵 |
| 古修遗府 | 功法/丹方/法宝 | 探索奖励，替代 X4 的蓝图 |
| 基地建设 | 洞府建设 | 丹房/器堂/灵田/阵眼 |
| 防守 | 守山/护山大阵 | 妖兽潮/宗门战 |
| 地图分区 | 灵脉节点 | 争夺焦点 |

### 10.1 两种产品形态

**A. 洞穴修仙经营（推荐，体量小）**

- 玩家是一个小宗门的宗主，山门在一个洞穴里。
- 核心循环：挖灵矿 → 建丹房/器堂 → 收弟子 → 渡劫/守山 → 挖更深。
- 地图只有一张洞穴，深度分层，越深越危险、灵气越浓。
- 3 个道统、12 种商品、3 个 sink（渡劫/宗门战/妖兽潮）。
- 这个形态最接近现有项目，也最容易做出来。

**B. 修仙版 X4（体量大）**

- 玩家是一个宗门联盟的盟主，地图是一个山脉/洞天群。
- 多个宗门、多个灵脉、商队、坊市、宗门战。
- 需要更大的内容量和 AI，不建议小团队首发做。

### 10.2 一句话建议

**做 A，不做 B。** 用 X4 的经济结构，但把规模压到一个洞天、三五个宗门、十二种商品。修仙题材的优势是"境界"和"渡劫"提供了天然的数值层级和消耗事件，不需要靠几十个星区来撑深度。

## 十一、结论

修仙版 X4 经济不是不能做，而是**不能只换皮**。

- 换皮版：灵石=电池、飞船=飞剑、宗门=空间站。玩家两小时看穿。
- 结构版：修士=舰船、渡劫=战争、灵脉=阳光、道统=阵营、坊市=市场。玩家会觉得"这套经济本来就该长在修仙世界里"。

最值得做的三个设计：

1. **两层人**：外门弟子当消耗品，内门/真传当故事角色。
2. **渡劫作为可干预的消耗事件**：玩家可以选择稳或赌，失败留下道伤/身死。
3. **灵石的双重角色**：下品当燃料，中品/上品当货币，兑换有损耗。

最需要避开的三个坑：

1. 不要做银河规模，做一个洞天。
2. 不要让高阶修士一个人打穿经济，用境界压制和数量稀缺来控制。
3. 不要让玩家只管理不冒险，用分身/神识保留个人代入。
