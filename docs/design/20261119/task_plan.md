## 目标（一句话）

把《X4：基石》的经济结构迁移到修仙题材——不是换皮，而是换"经济主体"：修士=舰船、渡劫=战争、灵脉=阳光、道统=阵营、坊市=市场。

## 验收判据（取自文档 §9.4，原文照录）

- [ ] 玩家能在 30 分钟内跑通「采灵矿 → 炼灵材 → 炼丹药 → 弟子服丹 → 渡劫」一圈
- [ ] 停掉任意一种原料，成品产线在 10 分钟内可见地停摆
- [ ] 无宗门战时丹药/法器库存堆满、价格下跌、丹房减产；战时价格回升、丹房加班
- [ ] 玩家能在一个面板看到「每小时赚多少灵石、瓶颈在哪、哪个弟子要渡劫」
- [ ] 玩家不建灵田/膳堂则弟子增长慢产能低；建了则要持续投入灵草/灵石

以上均为**设计目标**，截至 20261124 尚未实现，因此全部未勾选。

## 关键问题

1. 这套经济与本次的「小队背包 + 装备队列」如何接？——文档 §2.3「修士的装备就是舰船的配装」已给出方向：法器/本命法宝/渡劫套装都是**要占装备队列的实物**，背包容量直接决定产能上限。
2. 数值表何时做？——依赖商品链与消耗口先冻结（Phase 2/3 已完成，可进 Phase 4）。

## 决策记录

| 决策 | 理由 |
|------|------|
| 做 A（洞穴修仙经营），不做 B（修仙版 X4） | 用 X4 的经济结构，但规模压到一个洞天、三五个宗门、十二种商品；修仙靠"境界/渡劫"提供层级与消耗事件，不需要几十个星区撑深度 |
| 修士 = 舰船，两层人（外门消耗品 / 内门故事角色） | 全当消耗品则玩家不心疼，全当角色则产能上不去 |
| 灵石双重角色：下品当燃料，中上品当货币，兑换有损耗 | 单货币会让"存着不花"成为最优解 |
| 必须加反雪球四条 | X4 原版最大缺陷是"没有维护费，雪球不可逆" |
