# 《觅长生》战斗与养成数据集（本地参考）

> 目的：把《觅长生》(Chalcedony Network, 2019) 的**功法 / 神通 / 悟道 / 炼器 / 法宝 / 状态**
> 等实际数值表落到本地，作为**本项目战斗系统的设计参考与数值种子**。
> 边界：**这是外部作品的资料转存，不是本项目设定**。不自动生效，不参与引擎计算。
> 相关档：`待办事项/战斗系统-资料调研.md`（两作设定对比与本项目地基盘点）、`docs/灵脉地图设定.md`（本项目五行真源）。

---

## 〇、一句话

觅长生把玄门的"五行相生相克"落成了**两条可计算规则**（相生=连击、相克=增伤），
再叠加一层**状态（buff）层**与**灵气牌池**，形成一套**全确定性、可离线复算**的战斗规则。
本数据集就是把这套规则与它背后的全部数值表抄下来。

| 各攻略站（游民/ali213/18183/9game/逗游/imxmx/playgame） | 状态与词缀释义、炼器配方型 | 中（互相印证后采信） |

⚠ **三条必须记住的口径警告**：

1. **版本漂移**：觅长生从 2019 到 2023 多次改数值（例：`化焰` 由"敌方受火伤+2"改为"受所有伤害-15%"；
   `炼筋` +40→+60；`霸体` 改为 -30%）。本数据集采信 **2022 年前后的稳定数值**，
   与本项目无关，若真要照搬请以"机制"为准、数值仅作量级参考。
2. **官方配置表 ≠ 最终表现**：wiki 自己写明"若有错误、遗漏，欢迎在评论区指出"；逆向出的炼器公式
   "实用性并不强，仅仅是对炼器原理的讨论"。
3. ⚠ **版权**：本文全部内容为**外部作品的游戏机制与数值**，仅作**学习/设计参考**，
   **不得直接复制进本项目的发行内容**（名称、文案、具体数值都应重写）。本项目只需借用**机制骨架**。

## 四、字段约定（阅读本文档时）

- 功法/神通效果里的 `X/Y`：均为"一层/二层/…/五层"的对应数值。
- `【词】`：状态或词缀（见 `06-状态与词缀.md`）。
- 灵气消耗写法：`2金+同` = 2 张金系灵气牌 + 1 张"任意同系"牌；`金+水+木+火+土` = 各 1 张。
- 前缀 `*` / `**`：原始攻略表里的标注（多为"稀有/门派秘传"层级），**语义未在来源中说明，原样保留**。
