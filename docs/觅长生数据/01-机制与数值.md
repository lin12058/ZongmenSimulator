## 一、五行相生相克（战斗核心规则）

```
相生：木 → 火 → 土 → 金 → 水 → 木
相克：金 → 木 → 土 → 水 → 火 → 金
```

| 关系 | 判定 | 战斗效果 |
|---|---|---|
| **相生** | 五行轮盘**相邻** | **连击**：上一技能属性满足条件 ⇒ 本技能**额外效果** |
| **相克** | **不相邻** | **增伤**：克制关系的出牌顺序 ⇒ 伤害提升 |

- 记忆法：**"相邻相生，不相邻相克。"**
- ⭐ 与本项目引擎一致：`ELEMENTS=['金','木','水','火','土']`、`SHENG=[2,3,1,4,0]`、`KE=[1,4,3,0,2]`（`Engine/js/mapgen.js:89-91`）。
- ⚠ 觅长生的**异灵根**（雷/风/冰/暗）不是独立行，而是**特定流派**（如【异火】）；
  本项目的 `DUAL` 表（`0|3雷 / 1|2风 / 0|2冰 / 3|4暗`）是**独立的异灵根派生**，两者口径不同，**不要混用**。

## 二、灵根

### 2.1 定义：权重向量（不是等级）

> **某属性灵气牌的概率 = 该属性灵根值 ÷ 五灵根值之和。**

- 灵根**只影响战斗中抽到哪种属性灵气牌的概率**。
- "灵根精纯和修炼速度挂钩，但**影响不大**"——灵根的主战场是**战斗**，不是成长。
- ⚠ 与《凡人修仙传》相反：凡人的灵根决定**修炼速度与上限**，觅长生的灵根决定**战斗资源**。

### 2.2 单/双灵根与"连击"

| 灵根 | 差异 |
|---|---|
| **双灵根** | 稳定抽到相生所需的**第二种属性** ⇒ **需要连击的流派必须双灵根**（占多数流派） |
| **天灵根（单）** | 不吃连击的流派（**剑修**、少数流派）可用；且天灵根可直接拜师、入门送法器 |
| 三灵根 | 神修 |
| 五灵根 | 禾山道 |
| 黑话 | **"遇事不决天灵根。"**（说明本作**没做好多灵根取舍**，参见调研档 §三） |

### 2.3 门派与官配灵根

| 门派 | 主修五行 | 推荐灵根 |
|---|---|---|
| 金虹剑派 | 金 | 金 / 金土 |
| 星河剑派 | 水 | 水（水剑天灵根最好） |
| 竹山宗 | 木 | 木水 / 木 |
| 离火门 | 火 | 火 / 火木 |
| 化尘教 | 土 | 土 / 火土 |

> 另见：白帝楼（金/土，剑修）、星宫（神识）、宁州散修、海外散修（无门派归属，功法池通用）。

## 三、境界

### 3.1 境界链

```
炼气 → 筑基 → 金丹 → 元婴 → 化神
每个大境界分 前期 / 中期 / 后期 三个小境界
```

- 前期→中期、中期→后期：修为满自动突破。
- 后期修为满 ⇒ **大圆满**；在洞府/客栈等可闭关处出现"境界突破"按钮。
- **5 次大境界突破**：筑基 / 结丹 / 化婴 / 化神 / 渡劫（**都是特殊关卡/boss 战式**，如筑基需攒"筑基点数"到 100）。
- 突破失败 ⇒ 损失一部分修为。

## 四、基础属性

| 属性 | 作用 |
|---|---|
| **年龄 / 寿元** | 寿元 = 年龄上限；到顶即"寿终正寝" |
| **资质** | 决定**修炼速度**；资质越高，基础修炼速度加成越高。也是**某些流派的入门条件** |
| **悟性** | 决定闭关时**感悟思绪**、领悟新神通功法、突破功法的效率（差 5 点 ≈ 学习 760 天变 790 天） |
| **神识** | 战斗 + 各种判定（海外探索、可见范围）；神识流晚成型 |
| **遁速** | 决定移动速度、**战斗先手**、**能否成功逃跑**（低于对方不可逃跑） |
| **修炼速度** | 每月被动积攒的修为值；由**资质 + 主修功法**决定 |
| **心境** | 影响闭关效率；**境界越高要求越高**。心境等级 < 境界要求 ⇒ 闭关效率 **-50%**；> 要求 ⇒ **+20%**。不影响战斗 |
| **灵感** | 论道时的重要状态。每月 +1，小境界突破 +50，大境界突破 +100；**上限由心境决定** |
| **灵根** | 见 §二（只影响抽牌概率） |
| **丹毒** | 见 §五 |

## 五、丹毒（服药副作用）

| 阈值 | 效果 |
|---|---|
| **< 50** | 每年自行 **-2** |
| **> 50** | 每回合抽牌 **-1**；每年自行 **-1** |
| **> 70** | 每回合抽牌 **-2**；**不再自行减少** |
| **> 100** | 每回合抽牌 -2；**每次施放法术 50% 失败，并失去 30 点生命** |
| **= 120** | **毒发身亡** |

> 另有 **耐药性**：同一丹药反复服用会累积耐药性，达上限后不能再服。
> ⭐ 设计价值：**把"嗑药变强"绑上一个单调恶化的负债**——这是"资源有代价"的干净范例。

## 七、悟道点（获取与上限）

> 详细规则与"道"节点表见 `02-悟道.md`。此处只列**点数来源**。

| 来源 | 数量 |
|---|---|
| **境界提升** | 每次练气突破 +1；筑基突破 +2；金丹突破 +3；元婴突破 +4；化神突破 +5 |
| **悟道境界** | 每条道达到"融会贯通"（30000）获取 1 点 |
| **论道** | 论道经验满足进度即得 1 点，**上限 30 点** |
| **丹药** | 5 品道源丹 1 点（可吃 3 颗）；6 品天道源丹 3 点（可吃 1 颗）；耐药双倍 |
| **天赋【转世仙人】** | 升大境界额外加：练气→筑基 +1、筑基→金丹 +2、金丹→元婴 +3、元婴→化神 +4 |
| **剧情** | 化神后龙宫龙墓奖励 +2 点 |

**点数上限（来源原文）**：练气 2 点、筑基 6 点、金丹 9 点、元婴 12 点（合计 29）；化神大圆满 15 点（合计 44）。
来源另称总计约 **110 点**（44 + 论道 30 + 丹药 12 + 转世仙人 10 + 龙墓 2 + 大道贯通若干）。

## 八、修炼 / 突破 / 论道的机制要点

- **灵气（手牌）**：每回合**吸收数量固定**（基础 **5** 点；元婴期五行功法加 2/4/6），
  但**属性按灵根权重随机 roll**；回合结束时灵气必须降到**上限**，超出部分**消散**（⇒ 不能无限屯牌）。
  - ⚠ "任何增加灵气**上限**的功法与悟道，**不影响**每回合灵气**吸收数量**。"（两回事）
- **提高吸收量的手段**：悟道（生X/相生/气道-抱朴）、宗门神通（每回合一次）、部分功法
  （一气分神决/阳春百花决/狂澜诀/玄青天衍录/蓄灵决…）、四品补灵丹、元婴期五行功法。
- **论道**：双方以"论点牌"碰撞合成更高一级论点，满足论题即成功 ⇒ 获"思绪" ⇒ 闭关感悟 ⇒ 悟道值/悟道点。
- **心境/灵感**：心境影响闭关效率与灵感上限；灵感影响论道加成。
