## 一、回合相位（理解状态的前提）

```
【回合开始】  ← 灼烧/毒 等在此结算；阵法在此触发；蓄势在此清空并结算
   ↓
【抽牌 / 吸收灵气】  ← 获得固定总量、属性随机的五行灵气牌；滞气/扰魂在此扣牌
   ↓
【施法阶段】  ← 依次打出神通，消耗灵气牌；连击/相生/相克在此判定
   ↓
【灵气消散】  ← 灵气降到上限，超出部分消散；消散本身可能被功法/悟道利用
   ↓
【回合结束】  ← 中毒/缠绕/疗/流血/剑气 等在此结算；部分功法在此给 buff
```

⭐ **关键观察**：觅长生把伤害分成**两类**，这是它最强的设计之一：

| 类型 | 例子 | 特性 |
|---|---|---|
| **技能伤害** | 神通打出的直接伤害 | 受【霜冻】层数削减、受【免伤】类效果削减 |
| **非技能伤害** | 【毒】【灼烧】【暗劲】【剑气】【蓄势】 | **无视【霜冻】层数与"天机阁修士的免伤"** |

> 原文：*"毒…他不是技能伤害，可以无视霜冻层数和天机阁修士的免伤"*；
> *"灼烧…也不是技能伤害，可以无视霜冻层数和天机阁修士的免伤，所以灼烧流也能随意碾压金丹天机阁修士"*。
> ⇒ **DoT（持续伤害）是对"高减伤/高抗性"敌人的专用解**。这是一条**干净、无歧义、可离线复算**的规则，极适合照搬。

## 二、状态总表

### 2.1 伤害类（回合节点结算）

| 状态 | 触发时点 | 效果 |
|---|---|---|
| **中毒** | 回合结束 | 受到**层数**点伤害（非技能伤害） |
| **灼烧** | 回合开始 | 受到**层数**点伤害（非技能伤害） |
| **暗劲** | N 回合后 | 触发层数对应伤害（非技能伤害） |
| **剑气** | 回合结束 | 对敌方造成**层数**点伤害（非技能伤害） |
| **蓄势** | 回合开始 | 造成**层数**点剑系伤害（非技能伤害）；**每受一点伤害移除一层**；回合开始时清空 |
| **流血** | 回合结束 | 受到等同于**自身已损失生命值 × 层数%** 的伤害 |
| **缠绕** | 每次使用技能时 | 受到**层数**点伤害 |
| **流血（法宝词条口径）** | 回合结束 | 失去层数点生命值 |

### 2.2 增伤 / 减伤类

| 状态 | 效果 |
|---|---|
| **易伤** | 受到的技能伤害**增加**层数点 |
| **减伤** | 受到的技能伤害**减少**层数点 |
| **增伤** | 造成的所有伤害增加（由【葵水】满三层转化） |
| **破体** | 受到的治疗效果**减半** |
| **避火** | 受到的火系伤害**减半** |
| **引火** | 火系伤害增加 |
| **驭X** | 本回合造成的 X 系伤害增加 |
| **振X** | 下一次技能造成的 X 系伤害增加 |
| **焰** | 每有 1 层，火弹/火系伤害 +1；本回合造成的火系伤害增加层数点 |
| **葵水** | 满 3 层后移除所有，获得【增伤】*1 |

### 2.3 防御 / 护盾类

| 状态 | 效果 |
|---|---|
| **护罩** | 抵挡层数点伤害；**不在回合结束消失**（跨回合保留） |
| **气血** | 生命值上限提升 |
| **化焰** | 每次受到伤害时，**反弹**敌方层数点火属性伤害；回合结束获得【灼烧】*1；**使用任何非火系技能都会离开化焰状态** |
| **反伤**（法宝） | 每次受到伤害时，反弹敌方伤害 |

### 2.4 灵气 / 抽牌类

| 状态 | 效果 |
|---|---|
| **聚气** | 抽牌阶段**多抽牌** |
| **滞气** | 抽牌阶段**减少层数抽牌数**（但不影响"直接获得卡牌"的效果） |
| **扰魂** | 抽牌阶段，**抽牌数减半** |
| **凝滞** | 每使用一次技能**丢弃一张牌** |
| **跳过弃牌** | 回合结束**不会因手牌上限弃牌** |
| **魔气** | 体内存在魔气时，每回合**不能使用超过 5 次技能**，且每次使用技能受到 **5X** 点伤害（X = 魔气牌数） |

### 2.5 时序 / 行动限制类

| 状态 | 效果 |
|---|---|
| **冰霜 / 霜冻** | 减少层数的技能造成的伤害（**每 1 层少 1 伤害**，每回合减 1 层） |
| **冻结** | **免疫【霜冻】**，跳过下一次出牌阶段 |
| **冻结（神通口径）** | 本回合跳过施法阶段 |
| **束缚** | 本回合**最多只能使用 3 次技能** |
| **力竭** | **下回合跳过施法阶段** |
| **隐匿** | 有 **50% 几率闪避所有伤害**；使用任何技能都会破除（部分神通不破除） |
| **幻雾** | 有 **5% 几率闪避技能伤害**，每回合结束后移除一层 |
| **速 / 缚足** | 遁速提升 / 下降 |
| **神殇** | 降低神识 |
| **凝神** | 提升神识 |
| **威压 / 修罗低语 / 星魂之力** | 星宫系专属神识类状态 |
| **真龙之血** | 每回合减少（层数 ×10）的随机负面状态层数 |
| **真龙之体** | 每回合吸收灵气数量 +1（最多 +10） |

### 2.6 派系指示物（纯资源，供特定流派消耗）

| 指示物 | 归属 | 用途 |
|---|---|---|
| **惊涛 / 止水** | 星河剑派 | 相互转化；惊涛→剑气、止水→疗 |
| **尘 / 沙** | 化尘教 | 尘→护罩/振土；沙存于敌方可被【还尘】取回 |
| **引力** | 化尘教 | 增伤（每层 +消耗灵气数）、配合阵法翻倍 |
| **焰 / 化焰 / 灼烧** | 离火门 | 焰=增伤池；化焰=反弹+受伤减；灼烧=DoT |
| **魂** | 禾山派 | 增伤 / 回复（魂×4） |
| **剑气** | 剑系通用 | DoT + 大招消耗品 |
| **针** | 海外散修（鹤喙针/飞针术） | 连发弹药 |
| **幻雾** | 水系闪避 | 见 §2.5 |
| **星魂之力 / 影 / 针** | 星宫 / 鬼修 | 派系资源 |
| **凝神 / 神殇** | 神识 | 见 §2.5 |

## 三、词缀规则（神通的"触发条件"）

### 3.1 使用限制类

| 词缀 | 规则 |
|---|---|
| **【后继无力】** | **每回合只能使用一次**（神通常见词缀） |
| **【阵法】** | **会在你回合结束后触发一次效果**（阵法类神通常见） |
| **每场战斗限一次** | 部分神通明文限定（如`冰雨术`/`雾隐术`/`阴阳瞳`/`玄冰凝骨术`/`血祭噬魂术`/`枯灵劲`） |

### 3.2 条件触发类（⭐ 五行的落点）

| 词缀 | 条件 | 效果 |
|---|---|---|
| **【连击】** | 上一个使用的是 **X 系技能** | 触发词缀后的额外效果 |
| **【同】** | **全部**使用同系灵气牌释放 | 触发词缀后的额外效果 |
| **【生】** | 使用**相生**的灵气牌释放 | 触发词缀后的额外效果 |
| **【克】** | 使用**相克**的灵气牌释放 | 触发词缀后的额外效果 |
| **【神识】** | **神识大于对手** | 触发词缀后的额外效果 |
| **【剑意】** | 恒定 | **该技能使用会获得【剑气】*1**，且**属性视为"剑系技能"** |
| **【隐匿】** | 处于隐匿状态 | 触发词缀后的额外效果 |
| **【暗劲】** | 恒定 | 在体内种下一道灵气，**若干回合后**发挥作用 |
| **【异火】** | 恒定（火系高阶） | 标记为异火，可被火系功法/悟道统计 |
| **【形态转换】** | 恒定 | 改变自身形态（如`五鬼附身术`加血上限但受伤+1） |

### 3.3 效果类型类

| 词缀 | 规则 |
|---|---|
| **【吸血】** | 恢复等同于你造成伤害量的生命值 |
| **【恢复】** | 恢复数值的生命 |

⚠ **吸血的口径坑**：原文明确 *"对面有浑天术的效果、五府的翻倍不会让吸血数值增加，但尘衣、免伤等，会使我们无法吸血"* ——
即**吸血以"实际造成的伤害"为基数**，而**减伤会让吸血变少甚至归零**。这是一条容易实现错的规则。

## 四、可提炼的三条规则骨架（供本项目参考）

1. **伤害两分法（技能伤害 / 非技能伤害）**
   - 技能伤害：走"攻方伤害 × 增伤 × 克制 − 防方减伤/护罩"，可被【霜冻】削减。
   - 非技能伤害（毒/灼烧/暗劲/剑气/蓄势）：**绕过减伤**，是"抗性怪"的专用解。
2. **状态的双轨（层数 + 时点）**
   - 每个状态 = `(层数, 结算时点)` 二元组。时点固定为 `回合开始 / 施法时 / 回合结束 / N 回合后` 四选一。
   - ⇒ **实现上只需一张"时点表"** + 一个"层数累加器"，不必为每个状态写逻辑。
3. **指示物 = 流派货币**
   - 惊涛/止水、尘/沙、焰、魂、剑气……**全部是"先攒后花"的资源**，
     且**互相可转换**（土吸金气、水抽金气、尘↔护罩、惊涛↔止水）。
   - ⇒ 这是"卡牌流"能形成 build 的根因：**资源转换 = 策略空间**。

## 五、存疑与冲突（照抄前务必核对）

| 条目 | 冲突 | 处理 |
|---|---|---|
| **【阵法】** | `doyo` 写作"每场战斗只能使用一次"；`imxmx` 写作"会在你回合结束后触发一次效果" | 采信 imxmx（词缀专文），doyo 那条疑为转写错并 |
| **【隐匿】** | `imxmx` 注明"对方造成伤害 50% 几率会被躲避（**未实装**）" | 标记为**未实装**，勿按已实装设计 |
| **霜冻/冰霜** | 两个名字混用 | 同一状态，**统一叫【霜冻】** |
| **蓄势结算时点** | doyo 说"回合开始时清空并结算"；imxmx 说"敌方回合结束后造成伤害" | 实质一致（都是"跨过对方回合后结算"），描述差异 |
| **葵水 / 增伤** | 仅见 doyo 一处 | 低频状态，未在功法/神通表中出现，可能是旧版遗留 |
