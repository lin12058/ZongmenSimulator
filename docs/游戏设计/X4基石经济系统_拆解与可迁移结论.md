# X4：基石 经济系统拆解

调研时间：2026-11-19　｜　对象：X4: Foundations（Egosoft，中文译名《X4：基石》），含主要 DLC

一句话结论：**X4 的经济是"货物全真、货币半假"的战争经济。它模拟每一块矿石、每一个船体部件、每一艘运输船的飞行，但不模拟 NPC 的钱包；所有产能最终被战争损耗和空间站建设吃掉。**

这套系统值得研究的理由，不是它做得多完美，而是它用一套**能被单机 CPU 跑动的简化**，做出了"炸掉三跳外的一个工厂，另一头的船厂会停摆"的因果感。这背后有几条非常明确的设计取舍，可以直接搬到小体量游戏里。

---

## 一、先看全貌：五层结构

| 层 | 具体内容 | 模拟精度 | 玩家能做什么 |
|---|---|---|---|
| 资源层 | 小行星矿带、气体云、冰、阳光强度 | 每个矿点有储量，会耗尽并缓慢再生 | 采矿、放资源探测器、选矿区 |
| 生产层 | 空间站模块、配方、劳动力、储存 | 每个模块按固定周期扣料、产出 | 建站、加模块、招工、定产能 |
| 物流层 | 货船、矿船、买卖单、库存、跳跃门 | 每艘船真实飞行，每件货真实占仓 | 买卖、劫掠、封锁、设贸易规则 |
| 货币层 | Credits | 玩家侧收支真实；NPC 侧近似无限 | 定价、转账、投资 |
| 需求层 | 舰船损耗、空间站建设、人口口粮 | 船被击毁才产生新订单 | 开战、建设、倾销、断供 |

关键不在"五层"，而在**哪一层被简化了**。

X4 把最贵的两件事——"每个 NPC 的钱包"和"每个居民的终端消费"——直接砍掉，只留下"货物"和"产能"。NPC 势力不会因为没钱而不买，只会因为**没货**而不造。于是整个模拟的计算量从"经济体"降到"物流网"，这是它能在一台 PC 上跑几万个实体还不崩的根本原因。

## 二、商品链：四层，环状收口

### 2.1 层级

| 层级 | 内容 | 作用 |
|---|---|---|
| T0 原料 | 能量电池、金属矿石、硅、冰、尼维迪姆、氢/氦/甲烷、废料 | 采矿与太阳能获得，无上游 |
| T1 精炼 | 精炼金属、碲金属、硅晶片、石墨烯、反物质电池、超流体冷却液、水 | 把原料变成工业输入 |
| T2 部件 | 船体部件、先进复合材料、微芯片、智能芯片、等离子导体、量子管、扫描阵列、引擎部件 | 造船与建站的主干 |
| T3 组合件 | 武器部件、护盾部件、场线圈、先进电子、反物质转换器、导弹部件、炮塔部件、无人机部件、粘土电子 | 以两两组合为主，收口到少数终端 |
| T4 终产品 | 舰船、空间站模块、无人机、卫星、导弹、激光塔 | 最终被消耗或建造 |

### 2.2 最关键的设计：T3 是"环"，不是"树"

大多数工厂游戏的配方是树：一棵树一个终极产品，树枝越分越细。X4 不是。它的五个主干 T2 部件（船体部件、等离子导体、量子管、微芯片、先进复合材料）被设计成**两两组合**，产出六个 T3 部件，形成一个闭环：

```
(船体部件, 等离子导体) → 武器部件
(等离子导体, 量子管)   → 护盾部件 / 场线圈
(量子管, 微芯片)       → 先进电子
(微芯片, 先进复合材料) → 反物质转换器
(先进复合材料, 船体部件) → 导弹部件
```

六个两两组合的产品：

| T3 产品 | 配方 | 用途 |
|---|---|---|
| 武器部件 | 船体部件 + 等离子导体 | 舰船武器 |
| 护盾部件 | 等离子导体 + 量子管 | 舰船护盾 |
| 场线圈 | 等离子导体 + 量子管（同配方，不同模块） | 护盾调谐 |
| 先进电子 | 量子管 + 微芯片 | 炮塔、卫星、武器 |
| 反物质转换器 | 微芯片 + 先进复合材料 | 引擎、推进器 |
| 导弹部件 | 先进复合材料 + 船体部件 | 导弹 |

在这六个之外，还有三个**多输入 T3**，负责把多余的中间品收口：

| T3 产品 | 配方 | 用途 |
|---|---|---|
| 炮塔部件 | 微芯片 + 量子管 + 扫描阵列 | 炮塔 |
| 无人机部件 | 引擎部件 + 船体部件 + 微芯片 + 扫描阵列 | 无人机 |
| 粘土电子 | 量子管 + 微芯片 + 反物质电池 | **只用于空间站模块** |

这个环有三个直接好处：

1. **任何一条产线都和别的产线有交集**。你造武器部件，就必然需要船体部件和等离子导体；你想扩等离子导体，又会被石墨烯和冷却液卡住。局部短缺会自然传导。
2. **深度可控**。从矿石到 T3 最多四步，不会出现"为了造一个东西要先造六层中间品"的劝退曲线。
3. **粘土电子是唯一的"纯建设品"**。它不进舰船，只进空间站模块。这让"扩张"本身成为一个独立的商品需求，而不是战争的附属品。

### 2.3 四条经济链：用配方做阵营身份

| 经济 | 特征 | 设计作用 |
|---|---|---|
| 联邦通用链 | 上面那套完整四层链 | 大多数种族共用，形成统一大市场 |
| Terran 简化链 | 只有能量电池、金属微晶格、碳化硅、计算基质四种主料，链更短 | 泰伦空间自成一体，和联邦货不通用；玩家进泰伦市场要重新建一套 |
| Teladi 碲链 | 用碲金属替代精炼金属，配方相同但**不通用** | 强制泰拉迪空间有独立的冶炼产能 |
| 回收链（DLC） | 废料 + 能量 → 直接出船体部件/粘土电子，只限 Argon 技术 | 给玩家一条绕过采矿的替代路线，同时把"废料"变成战略资源 |

**这不是单纯的设定差异，是贸易边界。** 阵营专属链让"跨阵营贸易"有真实成本：你不能拿联邦的船体部件去修泰伦的船厂，也不能用泰伦的计算基质去补联邦的粘土电子缺口。地图上的政治边界，因此也是产业链的边界。

### 2.4 配方数值示例

| 产品 | 每周期输入 | 每周期输出 | 周期 | 每小时（单模块） |
|---|---|---|---|---|
| 能量电池 | 无 | 175 | 1:00 | 10,500（100% 阳光） |
| 精炼金属 | 240 矿石 + 90 电池 | 88 | 2:30 | 2,112 |
| 船体部件 | 280 精炼金属 + 40 石墨烯 + 80 电池 | 294 | 15:00 | 1,176 |
| 场线圈 | 40 等离子导体 + 43 量子管 + 60 电池 | 175 | 10:00 | 1,050 |
| 炮塔部件 | 20 微芯片 + 20 量子管 + 10 扫描阵列 + 60 电池 | 170 | 30:00 | 340 |

注意最后两行的差别：**场线圈每小时 1,050 个，炮塔部件只有 340 个**。越靠近终端，单模块产出越低、周期越长、占用的上游越多。这是用"时间"而不是"价格"来制造稀缺。

## 三、价格：库存驱动的限价单

### 3.1 三价与插值

每种商品有三个价：最低价、平均价、最高价。实际成交价不是市场撮合出来的，而是**按库存比例在区间内插值（近似线性）**：

- 库存接近 0 → 价格靠近最高价（缺货，买家加价）
- 库存接近满 → 价格靠近最低价（滞销，卖家降价）

| 商品 | 最低 | 平均 | 最高 | 区间宽度 |
|---|---|---|---|---|
| 能量电池 | 10 | 16 | 20 | 窄 |
| 金属矿石 | 43 | 50 | 58 | 窄 |
| 精炼金属 | 89 | 148 | 207 | 中 |
| 船体部件 | 146 | 209 | 272 | 中 |
| 炮塔部件 | 164 | 273 | 383 | 中宽 |
| 场线圈 | 247 | 412 | 576 | 宽 |

**区间宽度本身是设计参数。** 原料区间窄（矿石 ±15%），意味着采矿是"薄利多销"；部件区间宽（场线圈 ±40%），意味着加工和贸易有更大的操作空间。越是上游，价格越稳；越是下游，价格越能炒。

### 3.2 买卖单就是限价单

空间站的每一笔交易都是一个带价格的挂单：

- 买方挂"我最多出 X 价，买 N 个"
- 卖方挂"我最低卖 Y 价，卖 N 个"
- 玩家和 NPC 的船看到价差，自己飞过去成交

这套机制的好处是**不需要中央拍卖行**。每个空间站就是一个独立的小交易所，价格由它自己的库存决定。坏处是玩家必须理解"限价单"而不是"点一下就卖"。

### 3.3 利润 = 价差 − 时间 − 风险

一笔贸易的利润不是"卖价减买价"这么简单，还要扣：

- **时间**：船飞过去要几分钟到十几分钟，期间价格可能变
- **仓位**：货占着船舱，就不能接别的单
- **风险**：经过 Xenon 星区可能被击毁，货和船一起没
- **信息**：你不知道远处的价格，除非有卫星或船在那边

所以 X4 的贸易不是"低买高卖"四个字，而是"用信息和运力，把价差从空间上搬过来"。

### 3.4 信息是资源

价格不是全局可见的。要知道一个空间站的价格，必须有：

- 卫星/船在该星区（实时更新）
- 或者买该势力的**贸易订阅**（一次性付费，长期可见）
- 或者自己飞过去看一眼

这制造了一个很便宜的侦察玩法：**放卫星网络 = 买市场情报**。玩家在关键星门和船厂附近铺卫星，本质上是在建一张"价格雷达网"。

### 3.5 玩家可以改规则

玩家空间站可以：

- 手动定价（不用自动插值）
- 设"只和本阵营交易""只和盟友交易""和所有人交易"
- 对单个商品设黑白名单
- 设"只买不卖""只卖不买""库存到多少才卖"

这套规则系统是玩家把"自由市场"改造成"内部调拨"的工具。后期大帝国基本都会把内部交易锁死，只留终端产品对外卖。

## 四、生产：空间站是一台有人的机器

### 4.1 一个空间站由什么组成

| 模块 | 作用 | 是否必需 |
|---|---|---|
| 生产模块 | 按配方产出 | 工厂必需 |
| 集装箱/固体/液体储存 | 分别存成品、矿石、气体 | 必需 |
| 停靠模块 | S/M/L/XL 泊位 | 必需 |
| 居住模块 | 提供劳动力上限 | 想拿增产就必需 |
| 福利模块 | 加快劳动力增长 | 可选 |
| 防御模块 | 炮塔、护盾 | 可选 |
| 连接模块 | 把模块拼在一起 | 结构必需 |
| 造船模块 | 码头（S/M）、船厂（L/XL）、装备坞 | 终局 |

模块化本身不新鲜。X4 的特点是**模块之间有真实的物料关系**：生产模块要吃上游，居住模块要吃东西，造船模块要吃一整套部件。你不能只造一个"造船厂"，然后指望它凭空出船。

### 4.2 劳动力：食物换产能

- 居住模块提供床位，劳动力会随时间慢慢迁入
- 劳动力要吃**食物**和**医疗物资**，断供就流失
- 满员后生产模块获得增产，幅度随模块和产品不同，常见是几十个百分点
- 附近星球人口越多、站上有福利模块，劳动力增长越快

这条链的设计意图很清楚：**让"人口"成为一个需要持续投入的生产要素，而不是一个静态数字。** 你想拿增产，就得长期买食物和药；你想省钱不建居住模块，产能就低一截。

但 X4 在这里留了一个漏洞：食物和医疗的消耗相对产能来说太便宜，导致"建居住模块"几乎是纯赚。后面第八节会讲。

### 4.3 阳光：把地点写进配方

能量电池是唯一一个"配方里没有原料、但产出随地点变化"的商品。

- 每个星区有阳光强度，从 2% 到 1390% 不等
- 同一个太阳能模块，在 100% 星区每小时产 10,500 电池，在 1390% 星区产出高一个数量级
- 电池又是几乎所有配方的输入

于是"在哪建厂"不再是审美问题：**阳光高的星区适合做能源基地，矿带近的星区适合做冶炼，船厂近的星区适合做部件**。地图的物理参数直接进了经济计算。

### 4.4 资金：站点账户是隐形门槛

玩家空间站有独立账户。站点的管理员用这个账户里的钱下单：

- 账户没钱 → 即使隔壁有便宜原料，也不会买
- 账户有钱 → 才会挂买单、派船

新工厂"建好了却不动"，最常见的原因不是 bug，是**没给启动资金**。这让"开工厂"除了建材成本之外，还有一笔流动资金门槛。

### 4.5 物流：管理员星级决定半径

- 站点的矿船/货船，行动半径由**管理员星级**决定，大约 1 星 = 1 跳，5 星 = 5 跳
- 自由贸易船（不挂站）要 3 星飞行员才能自动贸易
- 所以前期的正确解法不是练飞行员，而是**建一个带管理员的站点**，用管理员的星级绕过飞行员门槛

这是一个很聪明的"用组织能力替代个人能力"的设计：你不需要一个王牌飞行员，你需要一个靠谱的站长。

## 五、需求：战争是最大的买家

### 5.1 船厂吃什么

| 站点 | 造什么 | 主要输入 |
|---|---|---|
| 码头 Wharf | S/M 舰船 | 船体部件、引擎部件、武器部件、炮塔部件、场线圈、反物质转换器、能量电池、食物、医疗 |
| 船厂 Shipyard | L/XL 舰船 | 同上，量更大 |
| 装备坞 Equipment Dock | 装备、维修 | 部件、电池、食物、医疗 |
| 泰伦码头/船厂 | 泰伦舰船 | 碳化硅、能量电池、金属微晶格、计算基质、MRE、医疗 |

每造一艘船，就从空间站库存里扣掉一整套部件。船被击毁，这套部件就永久消失，船厂就要重新下单。**这就是整个经济的主循环：矿石 → 部件 → 船 → 被击毁 → 再下单。**

### 5.2 建设也吃经济

建一个空间站模块（联邦），要消耗船体部件、粘土电子、能量电池。于是：

- 玩家扩张 → 吃建材 → 建材涨价 → 建材厂赚钱 → 更多人建建材厂
- NPC 势力也会扩张/重建 → 同样吃建材
- 战争打掉空间站 → 重建又吃一轮建材

**建设是第二个 sink，而且它和战争不冲突。** 战争打掉站，建设再建回来，两头的需求都在。

### 5.3 人口是二级循环

食物、水、医疗物资的消耗只跟劳动力有关，跟战争无关。这条链的特点是**稳定但上限低**：每个站都要吃，但单价便宜、消耗量固定，适合作为"保底收入"，不适合作为爆发增长点。

### 5.4 非法品是特殊需求

太空燃料、太空草、刺激剂之类的非法品，只在贸易站、海盗基地、黑市有稳定销路。它们的需求不受战争影响，但容量小、风险高（被查获）。这是一条"高风险利基"路线，不是主线。

### 5.5 Xenon：敌人也在同一套经济里

这一点很值得注意：Xenon 不刷船，也不作弊。它们和玩家一样，要用**能量电池、硅、矿石**造舰船和空间站；矿船被杀光，它们的船厂就会停摆。

这意味着：

- 敌人的威胁是**可以被经济手段削弱的**（断矿、炸矿船、封锁矿区）
- 敌人的扩张也是**有成本的**，不是脚本无限刷
- 玩家可以用"经济战"而不是"舰队战"解决一个势力

把敌人放进同一套生产规则，是 X4 最漂亮的设计之一。它让"经济"和"战争"不是两个系统，而是同一个系统的两端。

### 5.6 没有战争会怎样

会安静，但不会崩。

- 舰船不再损耗 → 船厂订单减少 → 部件库存堆满 → 价格跌到最低 → 工厂停产
- 空间站不再被毁 → 建材需求下降 → 粘土电子和船体部件滞销
- 玩家和 NPC 的船还在吃食物、医疗，二级循环继续
- 整个宇宙进入"低功耗待机"

社区里那句"玩家后期都会变成战犯"，说的就是这个：**不是玩家想打仗，是经济需要打仗。** 没有战争，就没有需求；没有需求，工厂就只是一堆会折旧的模型。

## 六、玩家的四条赚钱路径

| 路径 | 启动成本 | 利润来源 | 风险 | 上限 |
|---|---|---|---|---|
| 贸易 | 低（一艘货船） | 地区价差 | 海盗、Xenon、价格波动 | 中，受运力和信息限制 |
| 采矿 | 低（一艘矿船） | 原料无成本，卖价稳定 | 矿区被占、矿船被劫 | 中低，受矿点和需求限制 |
| 制造 | 高（蓝图 + 建材 + 启动资金） | 加工增值，越下游越赚 | 断料、滞销、被炸 | 高，可自给自足 |
| 造船 | 极高（船厂蓝图 + 全链） | 卖船给 NPC、自己组舰队 | 缺件停摆、NPC 压价 | 最高，终局 |

### 6.1 自动化阶梯

X4 的自动化不是一次性解锁，而是分三层：

1. **手动**：自己飞、自己买、自己卖。熟悉价格和路线。
2. **站点托管**：建站 + 管理员 + 下属船。管理员星级决定半径，下属船不需要高星飞行员。这是中期的主力。
3. **自由自动贸易**：3 星飞行员 + 自动贸易指令。后期才划算，前期练不出来。

这个阶梯的好处是：**玩家每一阶段都有"再往上一步"的目标**，而且每一步的瓶颈不同（先是钱，再是管理员，再是产业链）。

### 6.2 一局游戏的三段节奏

| 阶段 | 大致时长 | 玩家在干什么 | 经济瓶颈 | 情绪 |
|---|---|---|---|---|
| 前期 | 0–10 小时 | 做任务、捡水晶、手动贸易、买第一艘矿船 | 现金流 | 好奇 + 缺钱 |
| 中期 | 10–50 小时 | 建采矿站/贸易站、第一座工厂、招管理员、铺卫星 | 管理员星级、建材、启动资金 | 建设欲 + 被物流折磨 |
| 后期 | 50 小时+ | 复合工厂、船厂、舰队、挑动战争 | 需求（没有仗打）、缺件 | 掌控感 + 无聊 |

这张表解释了一个常见评价：**X4 的中期最好玩，后期最空。** 中期你每建一个站都能感到产能上升；后期你什么都建得起来，唯一的问题是"造出来的东西卖给谁"。这也是为什么社区会自发把"造船厂"当成终局目标——它是唯一能把产能重新变成"需求"的东西。

Single Player 的评测把这个问题说得很直接：进入 4X 阶段后，进度会突然变慢，最有效的策略常常是"等钱涨"；游戏又不给你足够的统计工具去判断"下一步该建什么"。**深度有了，节奏没跟上。**

## 七、设计意图：它为什么长这样

1. **让地图有经济含义。** 阳光、矿带、星门距离、阵营边界，全都进配方和成本。地图不是背景板，是生产函数的一部分。
2. **让因果可见。** 炸掉一个量子管工厂，三跳外的船厂会因为缺件停摆。玩家能亲眼看到"我干的"。
3. **用战争做终极 sink。** 生产出来的船必须被消耗掉，否则经济会堵死。战争是最自然、最有戏剧性的消耗方式。
4. **用信息差做侦察玩法。** 价格不可全局见，卫星和贸易订阅就是"情报投资"。
5. **用资本门槛控制节奏。** 蓝图、地块、建材、启动资金，四道门槛把扩张速度压住。
6. **用"人"做自动化门槛。** 管理员星级、飞行员星级，比科技树更有叙事感。
7. **用阵营专属链做贸易边界。** 政治边界不只是声望，还是"你的货我用不了"。
8. **让经济可以被"看见"。** X4 的货船是真船，玩家可以跟着它飞、拦它、炸它。数字不是报表，是空间里的实体。这是它能让人产生"我在经营一个宇宙"的错觉的关键——经济必须可被观察、可被干预，而不是藏在菜单里。

## 八、它的问题：社区十年实测的坑

这一节比前面更重要。X4 的经济系统被玩了几千小时，坑已经被踩得很清楚。

### 8.1 需求单一：和平 = 停滞

**现象**：不打仗，船厂不造船，部件卖不动，工厂停产。
**原因**：终极 sink 只有战争和建设，建设又主要由战争驱动。
**后果**：玩家后期必须主动挑事，或者用 mod 加需求。这不是"玩家选择"，是系统逼的。

### 8.2 没有维护费：雪球不可逆

**现象**：矿船和工厂一旦建成，就是永动机。没有工资、没有维护、没有税。
**原因**：运营成本被砍掉了，只剩一次性建设成本。
**后果**：前期越滚越快，后期钱多到没意义；玩家只能自我限制（不建船厂、不抢船）来维持挑战。

### 8.3 物流 AI 不会站间调拨

**现象**：上游工厂堆满，下游工厂缺料，站属货船却在运别的东西。
**原因**：管理员按"最赚钱的单"派船，不按"内部供应链优先级"派船。
**后果**：玩家必须手动把上游售价拉到最低、下游买价拉到最高，再用贸易规则锁死，才能让货流起来。所谓"自动"，其实是"手动配置出来的自动"。

### 8.4 玩家船厂被 NPC 压价

**现象**：玩家船厂接 NPC 订单，结算价远低于手动卖船价（社区实测约三成）。
**原因**：防止玩家用船厂刷钱的价格惩罚。
**后果**：终局最重资产的生意，反而不如直接卖部件；玩家用 mod 去掉惩罚。

### 8.5 数据不可观测

**现象**：没有"这个站过去一小时赚了多少""这条链的瓶颈在哪"的统计面板。
**原因**：UI 只展示当前库存和订单，不做历史聚合。
**后果**：玩家靠 wiki、表格、外部计算器做决策。经济越深，界面越应该给分析工具，X4 这里是最明显的短板。

### 8.6 建站是"拼图 + 等待"，不是布局优化

**现象**：模块摆放基本不影响效率，只影响外观和飞行时间。
**原因**：没有传送带、没有管线、没有空间约束带来的产能耦合。
**后果**：建站乐趣来自"造了个好看的大家伙"，不是"设计了一条更优的产线"。这和 Factorio 的乐趣是两回事。

### 8.7 大站卡顿 + 劳动力增长慢，逼玩家做"单细胞工厂"

**现象**：超级复合站劳动力填满要很久，还会卡；小站劳动力满得快，但物流麻烦。
**原因**：劳动力增长按站计算，大站床位多、增长慢；实体太多则吃 CPU。
**后果**：社区结论是"多建几个小复合厂"，而不是"建一个巨无霸"。这是性能倒逼出来的玩法。

## 九、对"洞穴探索"的可迁移结论

### 9.1 可以直接搬的七条

| 原则 | X4 的做法 | 搬到洞穴题材 |
|---|---|---|
| 货物全真，货币可假 | NPC 无限钱，但货物、产能、运输全真 | 只模拟"洞里的货"和"洞外的需求"，不模拟每个 NPC 的钱包 |
| 需求必须有终极 sink | 舰船被击毁、空间站被炸 | 深渊潮汐、怪物攻城、远征损耗、装备耐久 |
| 配方环状收口 | 5 个中级品两两组合成 6 个高级品 | 3 个中级品两两组合出 3 个成品，再向上收口两级 |
| 地点即参数 | 阳光、矿带、星门距离 | 深度、岩层、地热、通道长度、升降机容量 |
| 信息是资源 | 卫星、贸易订阅 | 侦察兵、测绘、信使、情报商 |
| 自动化分层 | 手动 → 站长 → 3 星飞行员 | 手动 → 工头 → 商队队长，用"人"的等级做门槛 |
| 经济可被看见 | 货船是真船，可跟、可拦、可炸 | 矿车、升降机、管道在洞里跑，玩家站在旁边就能看到货在流 |

### 9.2 必须避开的五个坑

| 坑 | X4 的教训 | 洞穴版的做法 |
|---|---|---|
| 无运营成本 | 矿船永动，雪球不可逆 | 每个单位吃口粮/工具磨损，或按班次付工资 |
| 需求单一 | 和平即停滞 | 至少两个独立 sink：防守消耗 + 建设消耗 |
| 物流 AI 不会调拨 | 玩家手动设价格 | 给"内部供应链优先级"一个显式开关，别让玩家猜 |
| 终局产品被压价 | 玩家船厂不赚钱 | 玩家卖终局产品给 NPC 时，价格至少覆盖全链成本 |
| 数据不可观测 | 玩家靠外部表格 | 内置"产线瓶颈/小时收支/库存天数"三个面板 |

### 9.3 洞穴版最小经济闭环

如果要把这套东西压到一个洞穴题材的小体量游戏里，建议只做**三层主链（原料 → 中间品 → 成品）+ 两级终产品 + 两个主 sink**：

| 层级 | 商品 | 输入 | 去向 |
|---|---|---|---|
| 原料 | 矿石 | — | 合金锭 |
| 原料 | 菌毯 | — | 菌粮、药剂 |
| 原料 | 地下水 | — | 药剂、菌粮 |
| 能源 | 地热 | — | 所有加工 |
| 中间品 | 合金锭 | 矿石 + 地热 | 工具、武器 |
| 中间品 | 菌粮 | 菌毯 + 地下水 | 工具、兴奋剂、口粮 |
| 中间品 | 药剂 | 地下水 + 菌毯 | 武器、兴奋剂、医疗 |
| 成品 | 工具 | 合金锭 + 菌粮 | 建设消耗、守卫装备 |
| 成品 | 武器 | 合金锭 + 药剂 | 防守消耗、守卫装备、远征装备 |
| 成品 | 兴奋剂 | 菌粮 + 药剂 | 远征装备、黑市 |
| 终产品 | 守卫装备 | 工具 + 武器 | 防守消耗 |
| 终产品 | 远征装备 | 武器 + 兴奋剂 | 远征消耗 |

对应到 X4 的结构：

| X4 | 洞穴版 | 说明 |
|---|---|---|
| 矿石/硅/冰 | 矿石/菌毯/地下水 | 三种原料，对应三种采集方式 |
| 能量电池 | 地热/荧光 | 地点参数决定产出，逼迫玩家选洞 |
| 精炼金属 | 合金锭 | 主干中间品 |
| 船体部件 | 工具 | 建设消耗的主力 |
| 粘土电子 | 轨道/照明 | 纯建设品，不进装备 |
| 食物/医疗 | 菌粮/药剂 | 人口维持，稳定消耗 |
| 舰船 | 远征队/守卫 | 会被损耗，产生再装备需求 |
| 战争 | 怪物攻城/深渊侵蚀 | 终极 sink，定期发生 |
| 卫星/贸易订阅 | 侦察兵/测绘 | 信息层 |
| 管理员星级 | 工头等级 | 自动化半径 |

**最小闭环的验收标准**：

1. 玩家能在 30 分钟内跑通"采矿 → 合金 → 工具 → 防守"一圈。
2. 停掉任意一种原料，成品产线在 10 分钟内可见地停摆。
3. 不打仗时，成品库存会堆满、价格下跌、工厂减产；打仗时，价格回升、工厂加班。
4. 玩家能在一个面板上看到"我每小时赚多少、瓶颈在哪"。
5. 玩家不建居住/人口模块，产能明显低一截；建了，就要持续买菌粮和药。

### 9.4 一个具体的落地方案

**商品数量**：3 原料 + 1 能源 + 3 中间品 + 3 成品 + 2 终产品 = 12 种，足够撑 20 小时，不会让玩家背表格。

**配方设计**：三个中间品两两组合出一个三角，再向上收口两级：

- 合金 + 菌粮 → 工具
- 合金 + 药剂 → 武器
- 菌粮 + 药剂 → 兴奋剂（高风险高利润）
- 工具 + 武器 → 守卫装备
- 武器 + 兴奋剂 → 远征装备

**地点参数**：

| 参数 | 影响 |
|---|---|
| 深度 | 矿种、温度、怪物强度 |
| 岩层 | 挖掘速度、支护成本 |
| 地热 | 能源产出 |
| 通道长度 | 运输时间、被截风险 |
| 空腔大小 | 可建面积、居住上限 |

**两个主 sink + 两个维持性消耗**：

1. **防守消耗**：每 N 天一波攻城，守卫装备和工事被消耗。玩家可以选择"打"或"交保护费"。
2. **建设消耗**：每挖一层新洞，要吃工具、轨道、照明。越深越贵。
3. **人口维持**：所有生产单位每天吃口粮，口粮由菌粮加工；不生产口粮的玩家，必须用成品去换。
4. **黑市**：兴奋剂可以卖给黑市换高价，但会引来查抄或道德代价（可选）。
