# 六道属性体系

> 六道是唯一投点处，其余一切数值都是算出来的。

## 一、为什么是六道

三道向内修己，三道向外施为。两两成对：

| 对 | 内修 | 外施 | 这一对管什么 |
|---|---|---|---|
| 形 | **体**（自身之形） | **器**（外物之形） | 能不能扛住、能不能捅穿 |
| 化 | **气**（天地之气入身） | **丹**（万物之精入口） | 灵气多不多、药毒狠不狠 |
| 意 | **神**（一人之意） | **阵**（众意连成一体） | 心神撑不撑、场域归谁 |

所以六道不是六个并列的圆盘，是三对拉锯：

- 内修决定**你还剩多少**（气血、灵力、神识三条命脉）。
- 外施决定**你打多狠**（武器、毒、阵法三条伤害线）。
- 对打时，外施先钻内修的壳：钻得进去外施赢，钻不进去内修赢。

一句话：**内修扛，外施钻。**

## 二、唯一源头：天赋点

| 约束 | 值 | 说明 |
|---|---|---|
| 出生总量 | 90 ~ 180 点 | 高天赋 = 高境界，不是白送的属性 |
| 单道上限 | 60 | 60 即"这道走到头" |
| 单道下限 | 0 | 允许完全不通（纯体修可以 0 丹 0 阵） |
| 合计关系 | 六道之和 = 天赋总量 | 面板上「一行六项」显示的就是这六个数 |

**铁律：六道之外不新增可分配属性。**
不为"力量""敏捷""智力"再开槽，也不为派生值单独开放加点。派生值全部只读，改了天赋/装备/特质才动。历史上"8 属性"就是因为太多又没用被砍掉的，六道是答卷，别再交第二份。

## 三、一道两个出口

每道只管两样东西：一门手艺、一门战力。这是六道能记住的唯一原因。

| 道 | 手艺出口（经营/宗门） | 战力出口（战斗） |
|---|---|---|
| 体 | 负重、劳作耐久 | 气血、防御、格挡、闪避 |
| 气 | 采药、耕种、吐纳 | 灵力、回气、法术强度、灵抗 |
| 神 | 研经、参悟、巡守 | 神识、精神攻击、控制强度、神识抗 |
| 器 | 炼器成器率 | 武器熟练（物攻/命中/破甲） |
| 丹 | 炼丹成丹率 | 毒攻、治疗强度（回血）、毒抗 |
| 阵 | 布阵成功率、阵域维护 | 阵法攻击、阵域半径、阵抗 |

## 四、公式总表

记 `B/Q/S/G/P/A` 为体/气/神/器/丹/阵的天赋值，各自 0 ~ 60。
装备词条为 `Σ装备.xxx`，特质为末位乘区。

| 派生属性 | 道 | 公式 | 量纲与用途 |
|---|---|---|---|
| 气血上限 MaxHP | 体 | 60 + 1.1B + Σ装备.hp | 生存 |
| 防御 DEF | 体 | 4 + 0.15B + Σ装备.def | 减物理伤 |
| 格挡减伤 BLK | 体 | 0.5% × B | 独立乘区，与 DEF 叠加 |
| 气血回复 HPR | 体 | 2 + 0.06B（每 6 秒） | 静养恢复 |
| 闪避 DODGE | 体+神 | 8% + 0.05%B + 0.10%S | 全额免伤概率 |
| 负重 LOAD | 体 | 55 + 0.9B | 超重则出手更晚 |
| 灵力上限 MaxMP | 气 | 24 + 0.7Q + Σ装备.mp | 施法资源 |
| 回气 REG | 气 | 2 + 0.15Q（每 6 秒） | 灵力恢复，战斗中折半 |
| 法术强度 SPD | 气 | 100% + 1.0%Q | 神通与法伤倍率 |
| 灵抗 RES | 气 | 0.4% × Q | 减法术伤 |
| 神识 SEN | 神 | 10 + 0.5S | 精神护盾值 |
| 精神攻击 PSY | 神 | 2 + 0.4S | 直击神识，无视防御与闪避 |
| 控制强度 CTL | 神 | 0.5% × S | 控制类神通的命中率与时长 |
| 神识抗 WIL | 神 | 0.5% × S | 抗控制、抗精神攻击 |
| 命中 HIT | 神+器 | 55% + 0.22%S + 0.30%G + Σ装备.acc | 命中判定 |
| 物理攻击 ATK | 器 | 8 + 0.4G + Σ装备.atk | 持械伤害基数 |
| 破甲 PEN | 器 | 0.4% × G | 结算时按此比例无视对方 DEF |
| 成器率 FORGE | 器 | 40% + 1.0%G | 炼器出成品概率 |
| 毒攻 POI | 丹 | 1 + 0.2P（每层每回合） | 持续真伤，无视 DEF |
| 治疗强度 HEAL | 丹 | 100% + 1.0%P | 丹药回血量倍率 |
| 毒抗 RES_P | 丹 | 0.35% × P | 减毒伤与中毒概率 |
| 成丹率 ALC | 丹 | 40% + 1.0%P | 炼丹出丹概率 |
| 阵法攻击 ARR | 阵 | 1 + 0.2A（每回合） | 阵域内真伤 |
| 阵域半径 R | 阵 | 1 + ⌊A / 25⌋（格） | 覆盖范围 |
| 阵抗 RES_A | 阵 | 0.35% × A | 抗对方阵域压制 |
| 布阵率 SETUP | 阵 | 40% + 1.0%A | 布阵成功概率 |

设计刻度：**专精一道（40 点）≈ 一到两件同品阶装备的加成**。天赋是慢变量，装备是快变量，两者量级必须同级，否则换装看不见效果。

## 五、逐道细则

### 体 · 炼体

六个天赋：铁骨、蛮力、坚韧、疾行、气血、硬功。

- 气血与防御是两条命：气血是池子，防御是把池子的水往外舀得慢一点。60 体 = +66 气血、+9 防御，等于凭空多穿一件中甲。
- 格挡与闪避分工明确：格挡按比例减伤，必中；闪避是全额免伤，看概率。体高的人不靠躲，靠接。
- 负重是经营的隐性成本：超重不改属性，改**出手顺序**（越重越晚），这是唯一一个"经营惩罚进战斗"的口子。
- 体不提供任何攻击。想打人，去器。

### 气 · 吐纳

六个天赋：纳灵、周天、绵息、速引、灵压、御风。

- 灵力是施法的油，回气是加油速度。40 气 = 42 上限 + 8/6秒，够连放三发二阶神通。
- 法术强度是**乘区**，不是平加：神通伤害 = 神通基础 × SPD。所以气道的收益随神通阶数放大，低阶神通吃不到。
- 灵压是气道的隐性用法：气高的人灵力上限高，被"抽灵"类手段打空得更慢。
- 气不给物理攻击，也不给毒。气是"量大"，不是"狠"。

### 神 · 神魂

六个天赋：凝神、观微、定心、神识、梦引、慑魂。

- **神识是第四条命脉，但不上常显状态条**：人物框仍是气血/灵力/心境/修为四条。神识在"能力"页显示为数值，战斗中受精神攻击才临时露出小条。
- 神识归零的后果不是死，是**心境骤降 + 无法施法与维持控制**。这让精神流成为"不杀人的赢法"，正好对上宗门经营里"收服而非屠灭"的调性。
- 精神攻击无视防御与闪避，只吃神识抗，所以它是唯一能绕过"体修肉盾"的正面手段，但代价是打得慢（不吃暴击、不吃破甲）。
- 控制强度与神识抗是一对：控制强度决定你控得准不准，神识抗决定你被控得久不久。
- 命中主挂神（观敌之隙），器只做补正。这是为了让"看不见的人打不准"这条直觉成立。

### 器 · 炼器

六个天赋：控火、辨材、淬锋、急就、器灵、重铸。

- 器是唯一给物理攻击的道。想把弟子练成打手，投器。
- 破甲与体是一对：器高的人专治甲厚的，20% 破甲等于把对方防御打八折。
- 成器率是宗门军备的产能：40 + 1.0G，60 器满值 = 100%，即"器宗不开废炉"。
- 器不给防御。炼器的人自己不经打，这是刻意的短板，避免"器体双修无敌"。

### 丹 · 炼丹

六个天赋：识药、控炉、保性、提纯、复方、丹毒。

- 丹道的战力出口是两条反向的线：**毒攻**（打出去）与**治疗强度**（收回自己）。同一个人两样都有，玩家自己选用途。
- 毒是真伤，无视防御，但吃毒抗，且毒抗也长在丹道上——**丹修互殴最难分胜负**，这也是刻意的。
- 治疗强度只放大丹药的回复量，不放大自然回复（HPR）。否则丹修躺着回满，战斗就散了。
- 成丹率 40 + 1.0P：60 丹 = 100%，这是六道里唯一"满值即无损耗"的指数（器同理），用来表达"匠人到了顶就不再失手"。

### 阵 · 阵法

六个天赋：布阵、阵眼、连纹、速设、掩息、破阵。

- 阵是唯一作用于**位置**的道：阵法攻击只在自己阵域内生效。人走阵灭，所以阵修要选战场。
- 阵域半径按 25 点一档：0~24 → 1 格，25~49 → 2 格，50~60 → 3 格。不要给小数半径，地图是格。
- 阵法攻击是每回合真伤且不占出手，这是它唯一的强度来源；代价是必须**提前布**，遭遇战布不出来（布阵率 + 速设天赋决定能不能应急）。
- 阵抗是"破阵"的另一半：高阵抗的人站在别人阵里不掉血，配合"破阵"天赋可以拔阵眼。

## 六、结算顺序（六个乘区，不许乱）

```
1. 基础常量        60 / 24 / 8 ...
2. + 天赋平加       1.1B、0.4G、0.15B ...
3. + 装备平加       Σ装备.hp / atk / def / mp / acc
4. × 天赋倍率       SPD、HEAL、BLK、PEN、RES 系列
5. × 特质          血旺 +15%、胆识 +10%、巧手 +20% ...
6. × 临时状态      中毒、阵域、心境、破甲标记
```

先加后乘，特质永远在天赋之后。否则"血旺 +15%"会因为先乘后加变成废条。

## 七、软相克（不做硬循环）

| 攻方 | 克 | 被克 | 机制 |
|---|---|---|---|
| 器（破甲） | 体（厚甲） | 体（格挡） | 破甲按比例穿 DEF，但格挡按比例减最终伤害 |
| 丹（毒） | 体（毒无视甲） | 气（灵抗） | 毒吃毒抗，灵抗减法术伤 |
| 阵（阵域） | 气（范围压制） | 神（神识抗 + 破阵） | 阵攻每回合磨，神识高的人扛得住场域 |
| 神（精神） | 阵（拔阵眼） | 体（精神打不动纯肉身） | 精神攻击绕过护甲但打不穿神识归零后的血条 |
| 气（法伤） | 器（无防） | 丹（毒抗） | 法伤吃灵抗，器修没灵抗 |
| 体（格挡） | 丹（抗毒） | 器（破甲） | 体是唯一能同时抗两条线的道 |

系数只做 ±10% ~ ±20%，不做"石头剪刀布必死"。宗门经营里打输应该是"回去补短板"，不是"这把没得打"。

## 九、与现有代码的差异（迁移清单）

当前 `web/js/crew/crew-model.js` 的 `attrs()` 与本表不一致处：

1. **物攻挂错了道**：现为 `atk = 8 + 0.12B`，本表改为 `8 + 0.4G`。迁移后 60 器 = +24（原 60 体 = +7.2），整体物攻上浮约 10%，需同步校准装备 atk 或敌方血量。
2. **防御系数偏弱**：现为 `0.05B`（60 体 = +3），本表 `0.15B`（60 体 = +9），使其与装备 def（6~18）同级。
3. **命中混装**：现为 `S` 单挂，本表 `0.22S + 0.30G`，器道补正。
4. **缺 15 个派生字段**：`sen / psy / ctl / wil / spd / reg / pen / poi / heal / arr / arrR / res / resP / resA / blk` 需新增到 `attrs()` 返回值。
5. **神识没有当前值**：`vitalOf()` 只维护 `hp / mp`，需加 `sen` 当前值（可先只存上限，简化）。
6. **`probe()` 需补断言**：派生值非负、`SPD ≥ 100%`、`arrR ≥ 1` 且为整数、`pen/blk/res* ∈ [0, 100%]`。
7. **面板不需改结构**：`attrRows()` 仍返回六道之和（一行六项），派生值放在"点开某一道"的展开层，避免重演"8 属性太多"。
