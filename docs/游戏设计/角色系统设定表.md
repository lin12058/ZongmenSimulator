# 角色系统

一个弟子由四样东西决定：灵根、天赋、特质、装备。灵根和天赋在出生时定死，特质随机，装备和神通靠后天培养。

## 灵根

灵根是五种灵气的吸收比例，金木水火土，加起来一百。它不影响修炼快慢，只管两件事：突破有多难，以及每回合能汇聚多少本系灵气。

## 天赋

每个弟子出生90-180点，随机点在上面，单个上限最大为60，投在六道上：体、气、神、器、丹、阵。每道六个天赋。

六道向内修三道、向外施三道，两两成对（形、化、意）。每道只出两样东西：一门手艺、一门战力。

| 道 | 手艺 | 战力 |
|----|------|------|
| 体 | 负重、劳作耐久 | 气血、防御、格挡 |
| 气 | 采药、耕种、吐纳 | 灵力、回气、法术强度 |
| 神 | 研经、参悟、巡守 | 神识、精神攻击、控制 |
| 器 | 炼器成器率 | 物攻、命中、破甲 |
| 丹 | 炼丹成丹率 | 毒攻、回血 |
| 阵 | 布阵成功率 | 阵法攻击、阵域 |

六道是所有数值的唯一投点处，气血/防御/法术强度这些全部算出来，不单独加点。逐道公式见 `六道属性体系.md`。

## 特质

特质是先天带来的，出生随机一到三条，只做一件事：把某项数值往上或往下拨一点。

每条特质都有对应的反面，同一个位置不会同时出现正反两条。特质不占天赋点，也去不掉。

## 装备

每个弟子身上五个格子：武器、副手、身体、头部、法宝。另有一个装备队列，法宝默认一件，点「分神」加一件、「万器归宗」加两件，最多四件；

## 神通

神通靠功法书学，不花天赋点，默认带三格，点「凝神」加一格。一阶到七阶分别对应炼气初期到元婴期，每个神通只写耗灵，从一点到六点，灵气不够就放不出来。
