2. **别用像素目测对齐**：crop 换算坐标三次全裁到空白。几何类改数值探针（DOM rect / probe 字段），截图只做"有没有、长什么样"的定性确认。
3. **headless chrome 要独立 `--user-data-dir`**：不带 profile 时 `--dump-dom` **exit=21 且输出 0 字节**（不报错、不提示），加独立 profile 立刻正常。
