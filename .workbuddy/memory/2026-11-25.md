- ⚠ 踩过一次：`bonus=1` 的辟谷单条吃到 **31%** 的权重（"人均辟谷"）。给辟谷定 2 分 + 加 `TRAIT_TIER_MULT` 把"高档稀"和"bonus 是游戏内强度"解耦后消失。
- 前端 `crew-model` 同步：`TRAIT_PAIRS.pos` 与 `TRAITS_SOLO` 全补 `bonus`、加 5 个同名常量、`genTraits` 换同款轮盘（实测 epic 0.14%/人、probe 4000 队 0 失败）。
- `checkCandidate` 新增三条断言：`bonus` 1~10、`highN ≤ CAP`、`bonusSum ≤ CAP`；`stats()` 增 `highPct / epicPct / traitBonusAvg`；roll 页 chip 显示 `+N` 加成分，底部多「异禀以上 / 天命 / 平均加成」。

### 百分比统一缩到 1/4（2026-11-25 追加）

- **定案**：所有**百分比**加成 = 原值 ÷4 四舍五入（`+50%→+13%`、`+35%→+9%`、`+20%→+5%`、`+10%→+3%`、`-30%→-8%`）；**点数值不缩**（气血 +10 / 心境 +8 / 神识 +1 格），它们本来就是绝对量。
- 改了三处：`chargen.TRAITS` 24 条文案、`crew-model.TRAIT_PAIRS`（pos+neg，旧档兼容也缩）、`crew-model.TRAITS_SOLO` 13 条；`attrs()` 倍率同步（1.15→+4%、1.25→+6%、1.18→+5%、1.20→+5%、1.06→+2%，旧负面 0.85→0.96、-8→-2）；`rateOf` 勤勉 1.35→1.09、懒散 0.70→0.92。
- ⚠ **小基数会被 round 抹平**：`def 19 × 5% = 0.95 → 0`。`attrs()` 里加了 `bump(v,pct) = v + max(1, round(v*pct))`，保证正增益**至少 +1 点**，否则 2~5% 的特质在面板上完全看不出来。
- 实测（基线 hp126/atk22/def19/dodge12）：血旺 hp131、胆识 atk23、龙象 hp134+atk23、铁骨 def20、耳目 hit65+dodge13。
- 守卫：`_dom_roll_check.mjs` 加「文案最大百分比 ≤13%」，以后谁再写 +20% 直接红。
