- **后端进程管理经验 (今天收尾)**:
  - 构建必须 `dotnet build Server/Zongmen/Zongmen.csproj` (MSB1009 是拿目录当项目文件; 只有 `dotnet run --project` 接受目录)。
  - 本机 curl 探测 127.0.0.1 必须 `--noproxy "*"`, 否则环境代理报 "upstream connect failed" 误判服务死。
  - run_in_background 起的 Zongmen.exe 会被外部终止 (用户手动 Stop / 会话清理), 日志无异常、戛然而止即"被杀"而非崩溃; 判定存活以 `curl --noproxy` meta/stats 为准。
  - 清理后台只需一条: `Get-NetTCPConnection -LocalPort 8140 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }`; node/chrome 残留此前均已清空。
  - 后台任务 failed 通知≠异常: 历史实例退出会陆续弹通知, 但实际存活进程可能只剩后端一个; 用 PowerShell CIM 盘点是唯一可信手段 (PowerShell 直出常被吞, 落盘临时文件再 Read)。
