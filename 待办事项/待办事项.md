## 山河图 · 个别色块无贴图（后端请求失败排查）

**状态**：进行中（已分析，待定位复现确认）

**现象**：地图上有某一个色块区域完全没有加载任何贴图（空白一片）。

**初步分析结论（按可能性排序）**：

1. 【最可能·边缘】`MapWorldService.BuildChunk` → `MG.buildChunk` 返回 `count=0` 的空块。该块 `chunk` 子消息为空包，前端 `uploadChunk` 传 0 个实例 → 空洞。
2. 【内部零星·重点排查】WebSocket rev 缓存误命中：客户端 `revs` 残留旧 rev，但该块已被卸载；再入视野时携带旧 `lastRevs`，服务端判定 rev 未变 → `Chunk` 子消息缺省不下发 → `resp.chunk=null` → 块永远空白。检查 `blockForget` 与 `chunkData.delete` 的时序是否一致。
3. 【全局卡死】后端 V8 引擎单机门闩被某次 A* 寻路阻塞，阻塞整条 WS 处理线程，后续块全部排灰。看服务端日志是否停在某次 `chunkJson` 后无输出。
4. 合法空块：世界外圈纯海洋可能无精灵（`pn=0`），但地形仍应有——若连 hex 都没有才算异常。

**待办动作**：

- [ ] 用 `debug=1&capture=1` 打开页面，在 Console 查 `window.__data()` 与空白块对应 key 是否存在于 `chunkData`。
